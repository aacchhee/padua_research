## Safe retrieval and export

The revised helper requires POSIX directory-descriptor and `O_NOFOLLOW` protections for manifest loading, verification and mutations. Use Linux/macOS where these primitives are supported, or WSL for AC's Windows storage; unsupported native platforms fail closed for verify/restore/clean/export. Verification is read-only but uses the same guarded filesystem traversal. A WSL destination may be the authorized Windows directory mounted under `/mnt/c/.../Downloads/padua/cold_storage`; substitute AC's actual existing mounted path. No export to AC's machine has been performed.

Use **fresh non-worktree storage** for external destinations. At foreign destination ancestors and during payload traversal, restore/export/clean reject nonempty `.git` directories and `.git` files, symlinks or other nonregular markers. Empty `.git` directories contain no index and are ignored, including this managed environment's empty `/tmp/.git` and `/workspace/.git` sentinels. The helper source repository's own `REPO/.git` is allowed; operations under that source root use its own index to protect tracked destinations rather than treating outer ancestors as foreign. Nested worktrees are refused. Read-only `verify` keeps safe traversal and byte checks without applying the foreign-worktree mutation refusal. This guard does not authorize writing inside another worktree. Keep destination directories and repository indexes quiescent, and do not initialize a repository concurrently.

From the current repository root, restore a full historical copy into a **fresh non-worktree** scratch directory, verify it, and optionally remove matching restored artifacts:


`restore --dest DIR` writes `DIR/<repository-relative path>`; it does not add the slug. With no `--dest`, verify/restore/clean address the current repository worktree, where the active tracked manifest prevents whole-archive restoration. Both the slug and `topics/padua-argmax-alln-20261101` directory addressing are supported.

For delivery, use a POSIX/WSL path for AC's authorized `Downloads\padua\cold_storage` directory:


Export writes `DEST/padua-argmax-alln-20261101/<repository-relative path>` and `DEST/padua-argmax-alln-20261101/cold-storage-export-receipt.json`. It validates archive bytes and preflights destinations including the receipt. Matching files and the exact deterministic receipt are reusable; differing files, symlinks, unsafe paths and tracked destinations are refused without replacing them. Receipt content records the source, file identity list, total bytes and hash agreement; it omits a changing timestamp to support exact idempotence. Clean removes only matching ordinary untracked archive copies; it does not remove the receipt or directories.

Preflight avoids known collisions before writes. A later I/O error may leave completed matching files and a partially written new file. Inspect/remove only that partial new file manually before retrying; completed matching files are reusable. The descriptor guards reject traversed symlinks and detect observed final-entry changes, but cannot make compare-and-unlink atomic. They do not prevent an actor from renaming an opened directory outside the root, modifying an open file or swapping an entry after the last identity check. Use a controlled non-worktree destination and quiescent repository index without concurrent writers or concurrent repository initialization; this is not an adversarial-concurrency guarantee or a transaction.
