## Preregistered claim and stopping boundary

Before any C02 numerical or exact arithmetic test, propose the following:

1. Delete the cotangent poles at 0 and pi, approximate the smooth residual
   by a fixed odd polynomial about pi/2, and apply N5's corrected midpoint
   rule only to the polynomial residual. Sum the polynomial exactly by
   a fixed-degree power-sum formula. Prove a geometric C4 tail and the
   resulting block error proportional to `q*h^4`.
2. Evaluate each positive shifted harmonic sum with a fixed explicit
   prefix and Euler–Maclaurin tail, retaining its uniform error even as
   the first sample approaches a pole. No hidden degree-growing sum or
   special-function implementation is allowed in the operation count.
3. Supply direct arc-to-index formulas and a guarded outward alternative
   that moves unresolved endpoint samples into a bounded direct set.
   Exact zeros and collisions use the finite polynomial, never `0*infinity`.
4. Assemble the truncation charges over every approximated row, with a
   constant number of exceptional rows retained exactly. For a declared
   finite degree ceiling, make the analytic error arbitrarily small using
   degree-independent work per block. Separate this from an unsupported
   uniform absolute error claim at unbounded degree: a fixed absolute
   harmonic error is amplified by `1+log n` in the current weight budget.

order J=96 and harmonic prefix K=64 / Euler–Maclaurin order L=32. Any
arithmetic diagnostic is limited to exact scalar bounds and small partial
