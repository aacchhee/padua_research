# Compact delivery draft

User will replace the old partial delivery. This new complete offline pack
keeps the unchanged scientific engine,30 workers and128GB decimal RAM cap,
but removes duplicate immutable library/build storage after validated passes.
The original released Syvert archives remain immutable.

Default return is one small ordinary tar.gz: all completed essential
primary/fresh certificates and accounting, plus complete raw/native/library
histories for TWO completed residual degrees sampled after the run. Seed,
eligible population and draw are recorded. Every completed full history is
validated on Syvert first; unsampled histories remain there and are not
claimed independently reviewed or transferred to cold storage.

Root checks all compact rational proofs and full sample closure, then
independently reruns the sampled native degrees in the sandbox. Source,
dependency pins, commands, exact degree scope and per-degree validation
hashes document regeneration. Actual archive size is printed; preferred
25MB transfer size is measured, not guaranteed. No evidence is truncated.

Saved known41/511 data suggests most of the old roughly14GB growth came
from repeated11MB libraries. Hardlinks remove those exact-byte duplicates
while retaining original paths. Unique TUs are1.25–1.67MB each, so full280
physical history may still be around1–2GB rather than a few hundred MB;
that is a planning estimate, not a bound. Benchmark the data-only copy
before release and publish its actual savings/return size here.

No new native run or residual degree occurs in preparation. Root fills
published source SHA, focused review, fixture measurements, new archive
SHA/bytes, runtime-manifest SHA and concrete transfer link before delivery.
Fresh unpack then `./run >run.log 2>&1`; completed cases now print progress.
After clean termination, `./collect_data --archive-directory ..` prints
the compact file to return. `finished_cases` tolerates incomplete JSON.
