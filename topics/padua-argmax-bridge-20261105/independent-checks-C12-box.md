## Source reconstruction

1. **Backend and full radii.** The author builder pins and includes the
   accepted C11 source `bde1ce48...`, whose actual constants are P=160,
   CP=640, J=16, K=32, LH=16 and WD=96. Its inherited C10 header comment does
   not select J48. Each `partial` returns the complete Arb ball, including
   the J16 smooth remainder, harmonic error, w-prime tail, 640-bit moment
   arithmetic rounded to P, and the explicit input-radius charge. C12
   multiplies that ball by the full arbitrary-vertex coefficient ball and
   sums the full signed result. No lower/upper endpoint or midpoint
   replaces it before that propagation.

2. **Actual terms before coefficient relaxation.** For each ordinary row,
   both whole-box real-index collision intervals are required to have
   literal outward width below one, then buffered by [-1,1]. Every integer
   in the closed buffer and both seam indices enters the fixed actual set
   D before vertices are constructed. Integer extraction checks finite
   values and `fmpz_fits_si`; the buffered bands contain at most three
   integers each, so |D|<=8. All D terms use the actual finite G primitive.
   This preserves cancellation at genuine collisions before artificial
   coefficients can destroy it. The four exceptional rows are entirely
   actual, with n terms each. If D is the whole row, no vertex work occurs.

3. **Convex rectangle.** Actual full-phase Arb enclosures of c and p are
   clipped to the proved ranges [-5,5] and [0,1]. Extracted ARF endpoints
   become radius-zero Arb values; duplicate endpoints merge. Thus the
   at-most-four vertices are exact dyadic choices, including p=0. This is
   coefficient convexity at a common physical phase and denominator. The
   subsequent interval propagation over phase can enlarge the result.

4. **Roots, cuts and signs.** The zero vertex returns zero; nonzero p=0
   gives a constant numerator. Exact |c|>p is root-free. Tangencies c=+/-p
   use the correct +/-pi/2 roots, and the general branch encloses all three
   alternatives theta, pi-theta, theta+2pi. Monotone asin endpoint clipping
   encloses the exact dyadic ratio's angle. Every actual root interval is
   again checked for width below one. Closed integer roots outside D enter
   the regular set E, with |E|<=3; empty bands still insert a cut. The
   retained seams cover the angular endpoints. The C09 no-root argument
   makes the numerator and denominator signs constant on each remaining
   core; source validates both at its left index and exact rational phase
   midpoint. Unresolved signs fail the entire row. A proposed cotangent
   wrap is accepted only after the whole supplied ball satisfies y>0 and
   n-y-(qcount-1)>0. No midpoint-only pole guard is used.

5. **Artificial vertices.** A regular E term is the full relaxed rational
   expression, with its denominator checked away from zero. Every core
   uses C=(p-c/sin(v))/4 and D=(p+c/sin(v))/4 and its certified sign times
   C*Qminus+D*Qplus. It includes all positive and negative cores directly;
   no original correlated signed row T or actual finite primitive is
   substituted for an artificial vertex. Ordinary sin(v) is separately
   checked away from zero. The vertex maximum is taken only after each
   complete successful vertex enclosure is obtained.

6. **Actual finite primitive and value-only ratios.** `finite12` uses the
   collapsed two-ratio G identity at the full alpha/beta balls, with the
   correct row parity and factor 1/2. Every ratio starts with the valid
   global [-k,k] range; a separated sine quotient may narrow it. A proposed
   integer turn does not justify anything by itself: full residual and
   scaled-residual upper bounds must satisfy the literal 1.5 and 4 guards.
   Entire sinc evaluation and the proved denominator interval [5/8,1]
   cover removable zeros. Folded monotone bounds use exact outward ARF
   endpoints and recheck those actual endpoints. Odd turns with even k
   change sign correctly, including negative turns. This is the general-k
   value theorem, with k<=4097 here; it uses no C03 derivative/curvature
   executable range or native k-squared/k-cubed arithmetic. A rejected
   optional chart retains a valid separated quotient or global range.
   The ratioFallback counter therefore does not count cap-only outputs.

7. **Fallback and totality.** Any ordinary-row exception discards the
   entire unfinished row computation and adds n*N. The actual cosine
   polynomial has absolute coefficient sum 2*N, so |G|/2<=N, proving this
   row cap. The same cap can tighten every completed row; S<=2*N is a valid
   final cap. Failed vertices are never omitted from a maximum. Retained
   rows can instead cause API failure, which makes no upper-bound claim.
   Native parsing rejects zero denominators before canonicalisation.
   Domain checks precede index loops, N and n*N are formed with Arb
   products, and all native indices/products are safe at the literal
   n<=4096 ceiling. Isolated phase vertices use the separate exact S=1
   theorem. Nearby boxes still execute the complete method.

8. **Count and error claims.** At most 4n retained actual calls, 8 actual
   samples, 12 regular vertex terms and 96 partial calls per ordinary row
   follow the C09 bounded component construction. The root/core loops have
   constant size; neither the production partial nor a rejected row scans
   all of its remaining columns. Precision and orders are fixed, with
   coarse fallback instead of unbounded adaptive retries. Thus the claim
   is O(n) scalar work, not constant-cost exact rational parsing or a bit
   complexity/throughput theorem. The relaxation diagnostic uses the
   actual dyadic rectangle widths and 2*Delta*(1+log(n))^2/pi. It bounds
   intrinsic convex relaxation, not final interval or fallback excess.
   The J16 tail diagnostic uses the actual backend's smooth allowance
   plus twelve per-block harmonic and derivative allowances, weighted by
   (1+5*(1+log(n)))/n. Disjoint core lengths sum to at most n per channel.
   The four-vertex maximum needs a uniform per-vertex bound rather than a
   sum over four vertices. These errors are already inside the propagated
   partial balls; the diagnostic is correctly not added again. Coarse
   fallback loss is outside both diagnostics.
