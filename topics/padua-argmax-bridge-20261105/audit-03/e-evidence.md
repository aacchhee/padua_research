  keys are the vertices of the numeric leaves plus the 13 D14 grid keys. These must equal the
  S-row set exactly. Hex values are parsed as exact binary64 rationals, and 0 < L ≤ W(0,0).
- **Norm premise.**
  - GRID: M ≥ 784·max₁₃W/663 (D14).
  - TREE: no f leaf, every retained θ_B < 1, and M ≥ max V_B/(1−θ_B) (D19 / D32 (17)).
- **Leaves (D32 (8)–(11)).** Exact θ_B with p_hi = 22/7 and κ = n/(n+1), U_B = V_B + θ_B·M, and
  r_B = min(1/2, p_hi(a_h+b_h)). The strict rules are:
  - FAR: U < L;
  - NEAR: 2p_hi·high ≤ 1 and U − δ < L;
  - SPLIT: both proxy branches, with Q_N nonempty iff low ≤ 1/(2p_lo).
  The bracket 157/50 < π < 22/7 is checked against π ∈ (3.1415926, 3.1415927).
- **Floor tier by degree** (D32 table / (12)):
  - 41..63: max(1/512, min(1/32, B));

  - 160..511: max(1/32, min(1/20, B)).

- **Corner.**
  - n < 256: the three D32 (15) physical keys, q = min(d_x/u′, d_y/v′, d_xy/(u′+v′)), and
    q > t = M·p_hi⁴·max(u′, κ⁴v′)/6.

## 8. Findings

**E-01 MINOR — verify_compact lets archive payloads shadow trusted package files.**
- Location: `compact_pack/verify_compact.py`, `reader()`: `if name in receipt['files']: return
  read_tar(name)`, before the package fallback.
- Reason: no check makes `receipt['files']` disjoint from the manifest's `files`. A return could
  therefore supply its own `topics/…/final_hybrid_engine/FREEZE.json` or `asset_provenance.json`.
  That would satisfy the freeze binding (`verify_essential(proof, proof['freeze'])` is
  self-referential; the binding is only the preceding digest comparison) and the sample
  arithmetic-pin check.
- Impact: none on the actual return [E]; the archive/package name overlap is empty. The checker
  code itself is always loaded from the package path, so the rational verification is unaffected.
  Only provenance binding is weakened.
- Fix: require `set(receipt['files']).isdisjoint(m['files'])`, and read ENGINE/ and
  `asset_provenance.json` only from the package.

**E-02 MINOR — the verifier used omits ledger, history and some link checks that the records rely on.**
- Location: `verify_compact.py` `check_pair` and `verify`.
- Reason: unlike `verify_return`/`archive_io.verify_admissions` and `verify_history`, it does not
  check:
  - the admission ledger (no retry) or the preflight/resume history;
  - fresh tree/keys equal to primary;
  - the per-pass summary `result`;
  - `validation_hashes.attempt_sha256` or the raw SHAs.
- Impact: none here. My independent check verified all of these [E]: 280 unique chained
  admissions, one non-resume epoch, 280/280 equal trees, and all hashes.
- Fix: add these checks, or cite this audit's independent check as the evidence for "no retry".

**E-03 NOTE — PASS does not by itself assert full coverage.**
- `verify_compact` accepts any sorted completed subset, by design for PA3. "Exactly 41..319
  plus 511" rests on reading the printed list, which matches here [E].
- Suggest an `--expect-plan all` flag requiring `completed == plan('all')`.

**E-04 NOTE — untrusted-return sizing.**
- tar members are bounded per member (≤ 512 MiB, < 200,000 members) and read fully into memory. The
  24 GiB aggregate bound is checked only after loading.
- A hostile archive can force memory exhaustion. This fails closed, not open.
- There is no extraction, hence no zip-slip. Symlinks and directories are refused; hardlink targets
  must precede.

**E-05 NOTE — engine-internal stage returncodes still use stdlib subprocess.**
- Location: frozen `engine.py` `stage_run` (`child.wait()`).
- Inside a normalized SIG_DFL process tree with the engine as direct parent this is sound, and
  stage acceptance also requires checkpoint COMPLETE and descendant accounting.
- Recorded so that a "PA1 everywhere" reading is not over-applied.

**E-06 NOTE — the residual trust boundary is correctly stated but can be narrowed cheaply.**
- For the 276 degrees not natively replayed outside Syvert, the outward premises (S uppers,
  origin lower, λ uppers) rest on the D23/D07 Arb kernels and the server run. The server "fresh"
  pass is a deterministic re-execution (280/280 bit-equal), not independent arithmetic.
- My four replays reproduce bit-equal premises on a different FLINT/MPFR/compiler stack. That is
  strong reproducibility evidence, but it is still the same kernel source and the same Arb algorithms.
- "No degree gap remains" is accurate as a coverage statement under G01's named trust; it is not a
  claim of independent arithmetic.
- **Cheapest confidence raise:** a local fresh verify replay of the 276 archive primaries not yet
  replayed (or all 280). Each primary is under 16 KiB and already inside this archive, so **no
  additional retrieval is needed**. Estimated cost is about 4.4k CPU-s, comparable to Syvert's
  verify sum of 4,537 s: roughly 20 min wall on 4 cores. It needs explicit authorization and its own preregistration.
  An independent second-implementation enclosure of a few retained points (e.g. MPFR-only) would
  address the implementation-trust axis.
