## Claim 1: all-n unisolvence and Newton recursion (T4-01). PROVED, verdict: ACCEPT

**Statement.** Take n ≥ 0, any distinct z_0..z_n ∈ [−1,1], and X_n = ∪_k Pad_{n−k} × {z_k} with Pad_0 = {(1,1)}. Then |X_n| = C(n+3,3), evaluation Π_n(ℝ³) → ℝ^{X_n} is bijective, and the residual Newton formula gives the interpolant.

**Reconstruction.** Restrict to z = z_0 and apply planar unisolvence. Then p − p|_{z=z_0} is divisible by (z − z_0) with a quotient of degree ≤ n−1, and induction finishes. In the recursion, ω_i(z_k) = 0 for i > k, and the residual equation reproduces f_k. Nested or commuting planar operators are not needed. Valid, including n = 0.

## Claim 2: exact height block determinant (T4-02, eq. 1). PROVED, verdict: ACCEPT

**Statement.** With fixed point and basis orders, det V(X) = ±_fixed · Π_k det V₂(Pad_{n−k}) · Π_{i<j} (z_j − z_i)^{N_j}, where N_j = C(n−j+2,2).

**Reconstruction.**
- The change from x^a y^b z^c to x^a y^b ω_k(z) is unit triangular.
- In the Newton basis, entry (layer l, group k) contains ω_k(z_l), which is 0 for l < k. So the matrix is block lower triangular.
- Diagonal block k is ω_k(z_k) · V₂(Pad_{n−k}), with determinant ω_k(z_k)^{N_k} det V₂.
- Reordering the columns contributes a fixed sign.

**Check (mpmath, 50 dps).** For every permutation of the Lobatto heights at n = 1..4, det V divided by the *signed* factor Π(z_j − z_i)^{N_j} took exactly one value per n (4.0, 54.0, −820.125, 1545.82438829…). Formula and fixed sign confirmed (MEASURED).

## Claim 3: Lobatto discriminant and comparison with the mean over permutations (T4-02, eq. 2). PROVED, verdict: ACCEPT

**Statement.** For Lobatto heights h_a = cos(aπ/n), n ≥ 1, and every permutation π:

log Λ(X_π) ≥ max(0, [S_n A_n − log D(π)]/N),

with S_n = C(n+3,4), N = C(n+3,3) and A_n = [(n+1) log n + (3−n²) log 2]/(n(n+1)).

**Comparison logic (the audit priority).** The argument is a determinant-domination bound, not a "the mean is larger" heuristic:
1. Let Y_σ be any other height assignment, with the same planar sets and with Pad_{n−j} at height h_{σ(j)}. Then Y_σ ⊂ [−1,1]³ and V(Y_σ) = L·V(X_π), where L_{ab} = ℓ_b(Y_a).
2. Row a of L has ℓ¹ norm λ_X(Y_a) ≤ Λ(X_π). Hadamard's inequality then gives D(σ)/D(π) = |det L| ≤ Π_a λ_X(Y_a) ≤ Λ^N; the planar factors cancel.
3. Therefore N log Λ(X_π) ≥ max_σ log D(σ) − log D(π) ≥ mean_σ log D(σ) − log D(π). The mean is used only as a lower bound for the max, which is a valid direction.
4. The witness points are the N nodes of the maximizing competitor stack Y_σ*: their Lebesgue-function values have geometric mean ≥ (D_max/D_π)^{1/N}. No single Lagrange function is used, and none is needed.

**Mean.** For fixed positions i < j, the pair (σ(i), σ(j)) is uniform over ordered distinct pairs, so the mean equals the average pair log-distance A_n. Then Σ_j j·N_j = S_n.

**Discriminant.** W = 2^{1−n}(z²−1)U_{n−1}. |W'| = 2^{1−n} n at the interior nodes and 2^{2−n} n at ±1. The product is n^{n+1} 2^{3−n²}. Re-derived by hand.

**Checks (mpmath).** Discriminant relative error ≤ 3e-51 (n ≤ 8); A_n against the direct mean ≤ 3e-42; exhaustive permutation mean minus S_n A_n ≤ 4e-20 (n ≤ 7). The exhaustive max gives a stronger bound (log Λ_M ≥ 0.978 at n = 7, against 0.682 from the mean).

## Claim 4: monotone exponential lower bound (PD-N T4-01). PROVED, verdict: ACCEPT

**Statement.** For z_k = cos(kπ/n), liminf_{n→∞} log Λ_M(n)/n ≥ 3ζ(3)/(2π²) = 0.18269074235035962468… The same holds for the reflected ascending order.

**Reconstruction.**
- f(s,t) = log(cos πs − cos πt) = log 2 + log sin(π(s+t)/2) + log sin(π(t−s)/2).
- For i < j with d = j − i, both sine arguments u satisfy min(u, 2−u) ≥ d/n. With sin(πu/2) ≥ min(u, 2−u), this gives log 2 + 2 log(d/n) ≤ f ≤ log 2, which is (3).
- The strip d ≤ εn contributes ≤ C'ε(1 + |log ε|) (via log q! ≥ q log q − q) and contains both singular corners. Off the strip f is continuous (sin(π(s+t)/2) ≥ ε), so Riemann sums converge.
- Replacing the weight costs N_j/n² − (1−j/n)²/2 = (3(n−j)+2)/(2n²) = O(1/n), times a bounded normalized |f| sum.
- J(t) = t log 2 + 2∫_0^t log sin πv dv = −t log 2 − Cl₂(2πt)/π. The Abel/dominated-convergence justification is correct.
- ∫ t(1−t)² = 1/12 and ∫(1−t)² sin 2πrt = 1/(2πr) (re-derived), so lim n^{−4} log D_M = −log2/24 − ζ(3)/(4π²). With n^{−4} S_n A_n → −log2/24 and N/n³ → 1/6 this gives the constant. Reflection z ↦ −z handles ascending order.

**Checks (all mine).**
- Direct quadrature of (1/2)∫(1−t)²J equals the closed form −0.0593295895817243253 to 20 digits; J(t) minus the Clausen form is ≤ 7e-41 at four sample t.

| L(n)/n | 0.09742 | 0.14061 | 0.17035 | 0.17949 | 0.18092 | 0.18172 |

- The gap is ≈ 0.26 log n / n. Least-squares extrapolation on n = 200..1500 gives 0.18269076 (target 0.18269074).
