## Claim 1 — parity balance; witnesses n ≤ 12; exclusion of n ≡ 2 (mod 4)

**Reconstruction (PROVED, verified).** Take N even and |X| = N. Then k ↦ k + N/2 is a free involution of X acting as R(x)_j = (−1)^{z_j} x_j. Because evaluation intertwines R, unisolvence forces D_t(n) = Σ_{|α|≤n} (−1)^{α_1+…+α_t} = 0. I rederived the generating function (1−t)^{t−4}(1+t)^{−t} and the closed forms: D = 0 (n ≥ 1) iff n is odd and t = 2, and N is odd iff n ≡ 0 (mod 4). So for n ≡ 2 (mod 4) **every** z and **every** real phase fails (|X| < N trivially). Degrees 2, 6, 10 are fully excluded; the permitted set ≤ 12 is {1,3,4,5,7,8,9,11,12}.

**Sanity checks:** closed forms equal enumeration for n ≤ 40; N odd iff n ≡ 0 (mod 4) for n ≤ 400; 55 random z and phases at n = 2, 6, 10 never exceed N − |D_t|/2 (33 attain it).

**Witnesses (exact-audit, own primes).** All 9 (n, z, phase) witnesses, transcribed from the theory table, have exactly N distinct nodes and rank N at two primes ≥ 1e9, up to rank 455 at n = 12. Odd-coordinate counts are 2 at every even N; at n = 12, N = 455 is odd, so there is no constraint.
