## Part 1 — double-Lee bound and n4..7 windows

The proof in double-lee-bound.md:28–46 is correct.

- **Diameter.** Pairs inside one ball differ by ≤ 2r. A cross pair a, e1+b′ differs by ≤ 2r+1, attained at (−r,0,0) and (r+1,0,0). So the diameter is 2n−1 < 2n.
- **Injection.** DS therefore injects into Z³/L, so |DS| ≤ [Z³:L].
- **Cardinality.** Each transverse shell s ≤ r has an x-fibre [−r+s, r−s+1] of 2(r−s+1) points, with 4s pairs per shell (one at s=0). Σ_s s(r+1−s) = r(r+1)(r+2)/6, so |DS| = (2/3)(r+1)(2r²+4r+3) = (2/3)n(2n²+1).
- It is always an integer, weaker than 38n³/27 exactly for n > 3, and equal at n = 3.

**Brute force n = 1..12** (`lee_brute.py`): set size = formula = shell sum, and diameter = 2n−1 for every n (2, 12, 38, 88, …, 2312). ALL_OK.

**Fresh enumerator** (`lee_enum.cpp`), unlike both existing implementations:
- every row HNF with adf = q, b < d, c,e < f;
- generic cofactor adjugate, with B·adj = qI checked at runtime;
- membership by dual forms, v ∈ L ⇔ v·adj ≡ 0 mod q, over the full half ℓ1-ball of radius 2n−1, with no pruning;
- fold from the group closure of the adj columns mod q (|H| = q checked, each h annihilates B).
