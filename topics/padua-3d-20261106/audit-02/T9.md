## 1. T9-01: retained-kernel lower bound

**Statement as reconstructed.** Take any bounded real linear projection P from C([-1,1]^d;R) onto Π_n^d. Then ‖P‖ ≥ ‖K_n^d‖₁, where K_n^d = Σ_{|k|₁≤n} 2^{-s(k)}e^{ik·t} and the L1 norm uses probability Haar measure. For n ≥ 1 this gives 3/4+3/(2π) in d = 3 and 1/2+2/π in d = 2. It covers every Π_n-unisolvent X ⊂ [-1,1]³, and nothing else is assumed.

**Proof check.**
- ‖JPJ⁻¹E‖ ≤ ‖P‖.
- The averaged operator R is a strong integral and is translation-invariant.
- Its multiplier is 2^{-s(k)} when |k| ≤ n, because E e_k = ∏cos(k_j t_j) is fixed. It is 0 when |k| > n, because the range of Q has no k-frequency.
- Haar normalization is consistent: K*g = ∫K(t−s)g(s)dμ(s) carries the probability Fourier coefficients.
- Real versus complex norm: complex characters are used only to identify R, through complexification and density. The norm bound itself uses real tests K/√(K²+ε²) with monotone convergence. For C(K) spaces the complexified norm would be the same in any case (sup_x‖μ_x‖_TV).
- Averaging over the subgroup (2π/n)Z³ is an L1 contraction. It leaves exactly the frequencies {0, ±n e_j}, and t ↦ nt preserves Haar measure.
- The box integrals (sympy) are (π−6)/(8π) in d = 3, giving 3(2+π)/(4π) = 1.2274648. In d = 2 they are (π−4)/(4π), giving (π+4)/(2π) = 1.1366198.

**Numerics (MEASURED).**
- The kernel identity holds to 8e-15. The subgroup average equals 1+Σcos(n t_j) to 2e-15.
- ‖K₁³‖₁ = 1.2884215 (quadrature error 1e-11) and ‖K₁²‖₁ = 1.1750805.
- ‖K_n³‖₁ on 192³ grids for n = 1..8 is 1.288, 1.511, 1.723, 1.905, 2.079, 2.233, 2.382, 2.516.
- Falsification attempt at n = 1. The Lebesgue function is convex, so its maximum sits at the cube vertices. 400 Nelder–Mead starts found:
  - minimum Λ = 2.0000 in the cube, at the alternate-vertex tetrahedron;
  - minimum Λ = 1.894427 = 1+2/√5 in the square.
  - These agree with Nevskii's values (auditor recollection).
- A linear program for minimal-norm projections onto Π₁, with functionals supported on 3³, 5³ and 9³ grids, gives 1.5 in both d = 2 and d = 3.
- At n = 2, 41 starts (including the T9 localdet set) gave a best Λ ≈ 3.2985, which is at least ‖K₂‖₁ = 1.51.
- Nothing below 1.2274 was found.

## 2. T9-02: square-wave dual

**Statement as reconstructed.**
- O_m = Σ_{a=0}^m 1/(2a+1), an odd harmonic sum.
- ‖P‖ ≥ (8/π³)Σ_{|k|≤n, all r_j odd} 2^{-s(k)}/(r₁r₂r₃) ≥ O_m³/(3π³).
- Here r(k) = (n+1)𝟙 + Ak, with A = [[-1,-1,-1],[-1,1,-1],[-1,-1,1]].

**Proof check.** Every step was verified:
- r_j ≥ 1;
- det A = −4, so the map is injective and t ↦ Aᵀt preserves Haar measure;
- ∫e^{irt}sign(sin t)dμ = 2i/(πr) for odd r and 0 for even r (sympy, r = 1..7);
- the phase i³ is common to every term, and Hölder against an L∞ test needs no continuity;
- the selected frequencies are k = (n−a₂−a₃, a₂−a₁, a₃−a₁). They give r = 2a+1 and |k| = n−2a₁, and the map is injective;
- each weight is at least 1/8, and the minimum-coordinate covering 3S₁ ≥ O_m³ holds even with ties;
- O_m − ½ log m → log 2 + γ/2 = 0.98176, so the leading coefficient is 1/(24π³), and 648/24 = 27.

**Numerics.**
- An independent enumeration over odd r-vectors reproduces the receipt's exact rationals at n = 1, 2, 4, 8 and 16. A direct loop confirms n = 32.
- S_n ≥ O_m³/24 holds for n = 1..60 (minimum ratio 4.23).
- Interval arithmetic, using exact rational O_m and an interval π at 60 digits, certifies:
