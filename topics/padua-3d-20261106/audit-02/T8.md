## Claim 1 — zero-phase cyclic reduction, cap, U/O census (PROVED reduction; MEASURED census)

Reconstructed: every finite cyclic H of (R/Z)^3 is {kz/M}, gcd(M,z)=1, M=|H|; each node has at most

**Verdict: the cap proof and quotients are correct** (t8-cyclic-reduction.md:47-62). The d=2 Padua

Independent census (`chk/audit_census.py`, imports no repository code). For coverage it does **not** use
unit reduction. It enumerates every sorted, individually folded primitive triple for M=1..8N, computes
the node count of each by vectorised exact integer folding, and keeps the N-node ones. It then
deduplicates exact reduced-fraction node sets up to axis permutation. Generator classes are counted
twice, by canonical minimum and by Burnside; the two counts agree for every M. Rank of each distinct
set is bracketed by two independent bounds:
- lower bound: F_p rank of the **monomial evaluation matrix at the actual nodes**,
  cos(2pi r/M) -> (w^r+w^-r)/2. Here w is a verified primitive M-th root (w^(M/q) != 1 for every prime
  q|M) and p ≡ 1 mod M is prime, giving the ring hom Z[zeta_M,1/2] -> F_p, so the F_p rank is at most
  the true rank;
- upper bound: an exact Fraction null-space basis of the unfolded character matrix. Each basis vector
  is checked to give g_v ≡ 0 mod x^M-1. Then 8p_v(x_k)=g_v(zeta^k)=0 at every node, so
  rank <= N - nullity.
Every set had equal bounds, so all ranks are exact. Results:

## Claim 3 — all-phase M=10 obstruction (PD-N T8-02) and half-period trace (PD-T T8-03), PROVED

Reconstructed and verified line by line:
- **Sign action.** cos(theta+pi z_j)=(-1)^{z_j}cos theta for every real phase. With 10 distinct
  nodes, k->k+5 is a free involution, so the nodal eigenspaces are 5/5. All-even z repeats nodes.
- **Pi_2 eigenspaces.** The trace is 1+(3-2r)+3+((3-2r)²-3)/2 = 4,2,4, so the eigenspaces are 7/3,
  6/4, 7/3. Intertwining gives rank <= 8, 9, 8. If |X|<10, the dimension count alone fails.
- **T8-03.** The first unit coordinate gives N=M/2+1 nodes. The fixed-node count is f=1 iff 4|M.
  D_r(n) matches the generating function (1-t)^-(4-r)(1+t)^-r. I checked the closed forms against
  brute force for n<=30, r=1,2,3. At odd n, 4|N, so M≡2 mod 4 and f=0.
- **D3.** In d=2 Padua, the half-period fixed nodes equal floor(n/2)+1, which equals the single-axis
  trace; checked for n=1..30. The d=2 M=N=6 analogue never reaches rank 6 (max 5, 720 random-phase
  cases), while Padua n=2 (M=12, folded) has rank 6. Padua therefore escapes by the hypothesis
  mismatch, not by vacuity.

Break attempts (`chk/audit_trace.py`), with no counterexample found:
- M=10, n=2: all 1,000 z with random real phases (6,944 ten-node cases) have maximum numerical rank
  8/9/8 by r. Over 36,252 rational-phase cases (phases in (1/120)Z³, all z), the F_p ranks, which
  are rigorous lower bounds, are all <= ceiling, with maximum 8/9/8. The ceilings are attained.
- E class: n=2 (all 171 (1,b,c) mod 18) max 9; n=4 (all 2,346, M68, f=1) max 34; n=3 with r odd
  (380 cases) max 17. All are <= the trace ceiling N-|D_r-f|/2. Any F_p rank of N would have been a
  rigorous counterexample.

Quantifiers: every z in Z³ and every phi in R³, but only at n=2, M=10. Hence only families that
include n=2 with M=N are excluded. The scope limit is real. At M=N=20, n=3, numerical rank 20
occurs in 541/1,116 random cases with r=2, while r=1/3 cap at 17. I **certified** unisolvent members
exactly by F_p rank 20 (`chk/audit_m20.py`), e.g. z=(1,2,7), phases (30,75,69)/120.
Omitted-n=2 sequences and other moduli are therefore correctly left OPEN.
**Verdict: both theorems PROVED as scoped.**
