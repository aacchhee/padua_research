### Proof reconstruction for (3)

Notation: θ=a+h with h∈H, and L=H^⊥. Expand T_α(cos 2πθ) = 2⁻ᵈΣ_ε e^{2πi(ε∘α)·θ}.

1. This gives E[h,α] = Σ_{r∈Zᵈ/L} χ_r(h)·B[r,α], where B[r,α] = 2⁻ᵈΣ_{ε∘α∈r} e^{2πi(ε∘α)·a}.
2. The character table [χ_r(h)] is invertible, and deleting repeated node rows keeps the row space. So the real evaluation rank on the distinct nodes equals rank_C B.
3. For β and ρ in the same class, (β−ρ)∈L. With 2a=h₀+m and m∈Zᵈ, (β−ρ)·2a is an integer, so e^{2πi(β−ρ)·a}=±1.
4. Scale row r by 2ᵈe^{−2πiρ_r·a}. This is an invertible diagonal operation and gives the integer matrix D. Rank over C equals rank over Q by minors.
5. This is an equality, so it also proves deficient ranks. Changing ρ or shifting a by an integer vector changes only row signs or even exponents.

For F: β·(uh₁+vh₂) = uf₁/a + vf₂/b. The class map is onto (take β_z=0). This gives exactly the recorded sign (−1)^{e₁(f₁−f₁₀)/a+e₂(f₂−f₂₀)/b}.
