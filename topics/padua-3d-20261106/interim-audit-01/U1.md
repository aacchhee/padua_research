## Reconstructed analytic claims

- **Recipe:** folding the two torus cosets gives the stated same-parity
  indices, endpoint multiplicities, positive weights and unit mass.
  Counting even and odd indices gives the two parity-dependent M formulas,
  including n=1. Strict monotonicity of cosine on[0,pi] proves distinctness.
  The local annihilator calculation admits only the nonzero frequencies
  ±(2n,0,0) below total frequency2n. Consequently only the(n,0,0) diagonal
  receives the extra unit, so `G=I+ee^T` and exactly that coefficient is
  halved. Equal orders give G=I. The `G>=I` factorization proves L2
  contraction and the stated twice-best-uniform-approximation bound.
- **Noise:** continuous orthonormality gives the integrated perturbation
  energy `||C epsilon||²`, hence `sigma² tr(CC^T)`. Positive diagonal W
  gives `W² <= w_max W`, and congruence gives the claimed trace bound.
  Averaging B/M independent observations changes node variance to
  `sigma² M/B`; therefore multiplying the trace by M is necessary and
  sufficient for the stated uniform-replication comparison. Deterministic
  bias is not multiplied or divided by M. No Gaussian assumption is needed.
- **OLS:** with D=C−C0, reproduction gives DV=0 and therefore
  `D C0^T=0`. Expanding covariance proves the positive-semidefinite
  difference and the Frobenius risk gap. This is a fixed-node, fixed-space,
  linear-reproducing, common-variance statement. It does not optimize
  degree, design, unequal variances, regularized estimators, or total error
  for a nonpolynomial target.

These are independently reconstructed exact arguments, not conclusions
inferred from floating tests. Their quantifiers are sound as written.
The numerical n=1 and odd-degree checks supplement the implementation
audit and are not proof premises. No previously accepted logarithmic
bound beyond the local Gram dependency was reopened.

## Findings and operational implications

### U1-M1 — MAJOR, public API silently accepts a truncated observation array

Location: `code/u1_usable.py:72–83`, specifically the broadcasting at79–80;
usage contract in `usable-recipes.md:23–34`.

At n4 the API requires45 observations. `parity_fit(4, np.array([2.]))`
instead returns35 coefficients of the constant2 polynomial, silently
broadcasting a single observation over all45 sites. A one-row two-channel
array similarly returns a35-by2 reconstruction of constants2 and3.
An ordinary M−1 vector does raise ValueError, so error detection depends
on the accidental truncated shape. Actual outputs are in the receipt's
`malformed_inputs` field.

Request: explicitly require n to be in the documented integer domain and
`values.ndim in (1,2)` with leading dimension equal to the generated M;
reject mismatches before multiplication. Preserve documented valid vector,
single-column, and multiple-channel behavior. The concrete failure is
the missing leading-dimension check; the extra domain checks are ordinary
API hardening, not new mathematical requirements.

This affects robustness of a public measurement-ingestion recipe, not
the proofs or any registered valid-input result. It is returned as MAJOR
because the remedy changes result-bearing code and lies outside WORKFLOW's
permitted auditor MINOR wording/link fixes. No producer code was edited.

A particularly transparent check uses `sqrt(2) T_(n+1)(x)`. At anisotropic
nodes with x=cos(pi*i/n), `T_(n+1)(x)=T_(n−1)(x)` for n>=2. Exact

orthogonality gives exact L2 error sqrt2. The n+1 QR interpolant reproduces
the target, with measured errors about2e−15 and3e−15 in the two cases.
This elementary audit counterexample uses different approximation spaces;
it is not a negative result about the stated Pi_n reproduction theorem.

Noise can reverse the deterministic choice. Combining empirical squared
Chebyshev bias for the x boundary layer with the exact-model fixed-budget
variance above gives an illustrative per-observation noise-sd crossover
about0.00347 at base8 and4.75e−5 at base12. These crossover estimates use
empirical bias and are not certified application thresholds. They explain
why a real noise/budget objective would make the next comparison useful.
