## IDEA?lanczos-nonproduct-codex-P4-04 — covariance-only finite-degree bound

Aliases: thin-annulus kill test; fixed distinct principal axes;
second-moment capacity control.

- Question / scope: a necessary preliminary for a quantitative covariance
  criterion is whether covariance and principal-axis angle alone bound
  the absolute capacity even at degree2. The original asymptotic iff
  candidate P4-01 is preserved separately and is not silently narrowed.
- Mechanism and hypotheses: use a uniform annulus with squared radius
  in [1-epsilon,1+epsilon], then scale y by2 so covariance has distinct,
  degree-independent eigenvalues. Its support hull is an ellipse and
  the measure is atomless. Test the last degree2 monic pivot/source.
- Closest full entries: IDEA130/134, PD-N012 support classifier,
  IDEA246 and P4-02/P4-03 normal quotient. The difference is an exact
  fixed-covariance family rather than measured loss or a support label.
- Separation criterion: if all these measures have identical covariance
  and axes but degree2 capacity diverges as epsilon->0, any universal
  finite-valued bound using only those data is refuted. This would not
  refute an iff about all-degree BJ/best exponential separation.
- Literature baseline/limits: repository gate only; no source theorem
  or historical-priority claim.
- Applicable obstruction: near algebraic support produces small pivots
  that second moments alone need not detect; sigma and d must both be
  tracked in the same monic source model.
- Verdict: new test variant within the documented bounded search.
- Cheapest test / prewritten kill: exact radial/angular moments and
  Gram–Schmidt through degree2 for epsilon=1,1/2,1/4,1/8; derive a
  quantified pivot/source formula. A covariance change, affine-product
  support, missing source normalization or nondivergent certified lower
  kills this specific test route.
- Discriminability: proves only a scoped lack of covariance-only
  absolute control. No cross-family N3 or growth verdict is inferred.
- Actual result: none at this dated preregistration.
- Disposition: retained for cheap exact/model test in round2.
- Canonical theory: to be written if the exact implication survives.
