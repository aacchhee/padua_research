## 2. Independent reconstruction

**Definition.** PD-T075 defines δ_obs(n) = sup{δ ≥ 0 : some nonzero real p ∈ Π_{2n+1} with p ≥ 0 on K_δ(n) = ∪B̄(z,δ) vanishes on P_n}.
- The balls are closed Euclidean balls in all of R² (PD-T058), not clipped to the square.
- P_n = {(cos jπ/n, cos kπ/(n+1)) : j+k even}.
- L5a's Δ(P_n, 2n+1) is identical. Its convention sup∅ = 0 is irrelevant for Padua, where 0 is always feasible.
- L5b–d restate the definition correctly, and U2 is untouched.

**L5a, re-derived: PASS.**
- *Upper certificate.*
  - For U > 0, a nonnegative vanisher has interior local minima at the nodes, so its node gradients vanish and p ∈ S1 = ker J.
  - rank_F = rank_R (by minors), so an F-basis spans ker_R.
  - Then 0 = Σλ_a p(w_a) with every term ≥ 0, so Ac = 0, and rank d gives c = 0.
  - Monotonicity in the radius then gives Δ ≤ U.
- *Existence.* Compactness of the coefficient sphere and interior rational density give 0 ∈ int conv, by a supporting hyperplane. Summing the representations of −v_a gives an all-positive dependence. The F-nullspace and rational approximation finish the argument. This is existence only, as the record states.
- *Lower certificate.*
  - λ_min ≥ det/trace.
  - For ‖h‖ = r ≤ L, |u|^a|v|^b ≤ r^{a+b}, so p ≥ r²(μ/2 − Σ_{k=3}^{D} S_k L^{k−2}) ≥ 0.
  - Every Taylor order up to D, every direction and the ball boundary are included.

**L5b (n = 3).**
- Field Q(√2) with √2 > 0; 10 nodes; degree 7; 36 monomials; J is 30×36.
- Lower bound: the 20-term pstar at L = 1/512.
- Upper bound: U = 1/2 on the q8 grid, with 12 points and 12 weights in F.

**L5c/L5d (n = 4, 5).**
- Fields Q(√5,√2) and Q(√5,√3).
- P_n = 9(g1² − g0g2/2) + g2² − g1g3, with g_m = T_{n−m}(x)T_m(y) − T_m(x)T_{n+1−m}(y). This equals PD-T069's P_n and 10·certificate(n), where certificate(n) is the c = 1/10 combination.
- Vanishing, derived independently: at θ = jπ/n and φ = kπ/(n+1), cos((n−m)θ) = (−1)^j cos mθ and cos((n+1−m)φ) = (−1)^k cos mφ. So g_m = 0 when j+k is even, and the quadratic combination has zero value and zero gradient on P_n.
