## 2. Independent reconstruction

**Restated claim.**

*Setting.* Take a positive discrete measure, injective on Π_s (s ≥ 1), with N = dim Π_s, ordered by the graded monomial order. A complete admissible selection R picks, for each column k ≥ 1, an immediate monomial parent p(k) and a creator A_k ∈ {X, Y}. X is allowed iff j ≤ t−1 and Y iff j ≥ 1, giving 2^{s(s−1)/2} selections.

*Exact baseline.* Full-projection Gram–Schmidt, producing q*, β* > 0 and c*.

*Run model (1).*
- Start from an exact q_0.
- Form ŷ_k = A_k q̂_p + e_k, with ‖e_k‖ ≤ uλ_k‖A_k q̂_p‖. The budget is relative to the computed parent product.
- Project exactly onto all previous computed columns, then normalize exactly.
- The errors are arbitrary: they may be history-dependent, depend on u, be nonsmooth or be chosen with foresight. Each only has to respect its own per-column budget.

*Claims.* Let the constants (2)–(5) be built from exact data and the λ_k, and take any K ≥ max‖L̄*(i)⁻¹‖₂. Then for every 0 ≤ u ≤ r_R = min(1, 1/(2b), 1/(2d)):
- the run completes, with positive pivots and orthonormal columns;
- the bounds (6) hold;
- θ_s ≤ B_R(u) ≤ uKF + 4u²K[J + F(b+d)], which is (7).

Further claims: finite-class acceptance, its tolerance version (8), and decidability for represented algebraic inputs. An adaptive policy whose every chosen prefix extends inside the class 𝓕 completes for u ≤ r_all = min_R r_R and satisfies (9).

**Step-by-step check (all re-derived by the auditor).**

1. **Exact feasibility.** Multiplying by a coordinate is strictly monotone in the graded order. So A_k q*_p has a nonzero coefficient on monomial k, and positive-weight evaluation is injective; hence β*_k > 0. Also v_k ≥ β*_k > 0. L̄*(i) is unit lower triangular, so K ≥ 1.
2. **Lemma (10).** For equal-rank projectors, ‖P̃−P‖ = ‖(I−P)Q̃‖ = ‖(I−P)(Q̃−Q)‖ ≤ ‖Q̃−Q‖. Correct.
3. **Lemma (11).** r/β − r*/β* splits so that the error is ≤ 2‖r−r*‖/β*, for any nonzero r. Correct.
4. **Induction.**
   - (12): ŷ−y* = A(q̂_p−q*_p) + e, so its norm is ≤ uλ(v + ah_p).
   - (13): r̂−r* = (I−P̂)(ŷ−y*) − (P̂−P*)y*.
   - The pivot bound β̂ ≥ β*(1−ub) ≥ β*/2 is established **before** dividing by β̂.
   - **Noncircularity verified:** every constant depends only on exact data, the λ_k, and h_l for l < k.
5. **Coefficients.** The bounds D_kl and T_kl(i), the Δ bound (14), and Neumann with ud ≤ 1/2, which gives K̂ ≤ K/(1−ud). Correct.
6. **Source and span.** f_k = −e_k is PD-T142's exact residual relation, and all PD-T142 hypotheses hold (σ_min = 1). So ε_s ≤ u(F+uJ)/(1−ub) and θ_s ≤ B_R(u).
7. **Remainder.** The identity B − uKF = u²K[J + F(b+d) − uFbd]/[(1−ub)(1−ud)] was verified in sympy. The denominators are ≥ 1/4, which gives (7); and B ≤ 4uK(F+J) gives (8).
8. **Finite selection and tolerance.** Immediate, since the minimizer is fixed from exact data before the run.
9. **Adaptive.**
   - The prefix constants depend only on the prefix and the per-column λ.
   - For any completion of the prefix, u ≤ r_all ≤ 1/(2b_R), so the next pivot is positive whatever the later edges are.
   - The realized complete path lies in 𝓕, so the fixed-path theorem gives (9).
   - No tie margin or continuity is used, so policies that switch at exact ties are covered.
10. **λ = C_loc comparison.** F ≤ C_loc√(N−1)χ_R. Correct.
11. **Computability.** The constants are algebraic; the Frobenius norm of the inverse is a valid K; real-algebraic comparison decides acceptance. Correct.

**Structural facts proved by the auditor, not stated in the record.**
- **(a) The term 1/(2b) never binds.** For the k attaining b, D_kl = X_k + v_k h_l with X_k ≥ 0. So Σ_l D_kl² ≥ C_k²/2, hence Δ ≥ √2·b, and K ≥ 1 gives d ≥ √2·b.
- **(b) The radius has a universal ceiling.** v_k ≥ β*_k gives h_k ≥ 2H_{k−1}, so H_k² ≥ 5H_{k−1}² and b ≥ 2λ_1·5^{(N−3)/2}. Therefore r_R ≤ 5^{−(N−3)/2}/(4√2λ_1) for every measure and every selection. With λ ≡ 1 this is below 2^−53 for all s ≥ 9.

**Edge cases.**
- s = 1 needs no modification.
- λ ≡ 0 gives r_R = 1 and B ≡ 0.
- Mixed zero budgets are handled by the ∞ convention.
- Zero errors give θ = 0.
- The pivot bound is attained with equality at k = 1, but by (a) β*/2 is never approached within the radius.
- u = r_R exactly is covered, since all the inequalities are non-strict.

**Verdict on the proof:** complete and correct as written; no gap.
