## 2. Independent reconstruction

**Setting (n ≥ 2).**
- m = n+2, s_k = cos(kπ/(m+1)) and v_k = 2sin²θ_k/(m+1).
- Nodes (s_k, 2s_k+s_l) with weights v_k·v_l, in √w-scaled Euclidean coordinates.
- BJ rule: X if j=0, else Y from (r, j−1). Mirror rule: X from (r−1, j) if r>0, else Y from (0, j−1).
- Each raw product receives an aggregate source εf_h. Projection onto all prior columns is exact, normalization is positive, and the start column is unperturbed.
- Source norm: Σ‖f_h‖²/σ_h², with σ taken from each rule's own exact run.
- Capacity: κ = sup over the unit source sphere of lim_{ε→0+} ‖(I−P_n)P_n(ε;f)‖₂/ε.

**Claims.**
1. κ_BJ ≥ √(2(4^(n+1)−1)/3) ≥ √2·2^n.
2. 0 < κ_mirror ≤ 2√6(n+1)²(N_n−1) ≤ 2√6(n+1)^4.
3. The ratio bound follows from (1) and (2).

Quantifiers: n is fixed, then f is fixed with ε → 0, then the sup is over f. No uniformity in ε is claimed.

**Match with the origin model.**
- PD-T136/137 use a uniform measure, monic columns b, output R[V]D^(−1/2) and σ = ‖A b_p‖.
- e1_exact.py's BJ rule (X iff j=0) and mirror rule (X iff j≠t), with increasing-j order, translate exactly into L1's (r, j) notation.
- Monic gauge: f̃ = 2^(−(d−1))f and V^mon = 2^(−d)V, and the factor 2^d leaves R[V] unchanged. The auditor's monic-gauge code reproduces the normalized checker's numbers exactly.
- So L1's κ is PD-T137's κ_s(J = all sources), carried over to positive weights. The weighted derivative is proved directly in §3, without PD-T138.

**Step-by-step check (all re-derived).**

§1:
- The geometric sum Σcos(2akπ/(m+1)) = −1 gives sine norms (m+1)/2 and Σv_k = 1.
- U_a(cos θ) = sin((a+1)θ)/sin θ gives (4) for a, b ≤ m−1.
- The top part of degree d, 2^d x^r (y−2x)^j, has its other degree-d monomials earlier in the order. This gives triangularity, S_d = span{q_rj}, and injectivity for d ≤ n+1 = m−1.
- M − N_n = (n+2)(n+3)/2. Formula (5) and Cov(X,Y) = 2E S² = 1/2 are correct.

§2:
- Formula (6) is correct, with indices ≤ n < m−1.
- Every creator expansion has target coefficient 1/2. All other terms precede the target (same degree with smaller j, or degree d−2), and none follows it. This is the admissibility condition that generic shears violate.
- So the exact runs give q_rj with pivot 1/2.
- (7) is correct. σ_(n,0)² = 1/2 needs n−1 ≥ 1, which is why n ≥ 2 is required. (8) holds.

§3:
- The perturbed relation is exact because the earlier perturbed columns are orthonormal; differentiating gives (9).
- By induction E_h ∈ S_deg h, which gives (11).
- With orthonormal columns ‖RP(ε)‖ = ‖RQ(ε)‖, which gives (12).
- The sup is taken of the norm of a linear functional, so no exchange of limit and sup is needed.

§4, BJ witness e = q_(n+1,0):
- The witness is not aliased (n+1 = m−1), and with e ⊥ S_n the source budget is 1.
- V_(n,0) = 2f. Each degree-n column has a single same-degree term with coefficient 1 and β = 1/2, so V_(n−j,j) = 2(−2)^j f.
- The output is rank one along e, normal to S_n, and unchanged by R_n. Its squared norm is ½·4·Σ4^j = 2(4^(n+1)−1)/3. This is an exact normal value, not an inference from raw entries.

§5, mirror:
- The c coefficients are exact, and (14)–(16) follow, with −4f_(1,j−1) also at j=1.
- The closed forms (17)–(18) were checked by induction; at n=2, V_02 = 2T(2f_01−4f_10) + 2f_02 − 4f_11.
- |U_a| ≤ a+1 on [−1, 1].
- The source sets f_(0,b), f_(1,c ≤ j−1) and f_(a≥1, j) are disjoint. Each coefficient has norm ≤ 4(r+1)(j−b+1) ≤ 4(n+1)², which is valid but loose.
- σ ≤ √(3/2), Cauchy–Schwarz and Frobenius give (20), using 4√(3/2) = 2√6.
- Positivity: the source σ_(0,n)e gives output 2σ_(0,n)e. Since H ≤ (n+1)², (3) follows with √6/√2 = √3.

**Robustness (the auditor's own argument).** All σ_h lie in [1/2, √(5/2)]. The exponential-versus-polynomial dichotomy therefore also holds for an absolute, unnormalized source norm, with changed constants.
