# Material for AC's later note

This is technical material for AC, not a sent message or a publication draft. Required Claude audit is still separate.

- In the PD-T432 node/relative-weight input box and NN fieldwise metric, diagonal polynomial gauges retain the b fields. The exponential Krawtchouk sensitivity survives fixed and differentiable gauges; the benchmark's exact exponential base is5+2sqrt(6). [Gauge proof](theory/c1-gauge-invariants.md), [sharp upper](theory/c2-sharp-upper.md), inherited PD-T437 lower.
- Scalar Jacobi controls grow slowly on N4–64 while the gauge-infimum MOP growth screen exceeds5 in both families. These are measured fits with explicit zero-field and fixed-mass conventions, not all-N scalar polynomial bounds or a metric-free claim. [Measurements](theory/c1-measurements.md).
- A parameter-dependent Krawtchouk lower base is explicit; its equality to the true rate outside the benchmark is unproved. [Formula and scope](theory/c2-krawtchouk-parameter-lower.md).
- The exact Hahn benchmark is normal for every N; a simple all-N lower base2 and a stronger terminal-row base12.1136005841… are proved. The latter supplies a full-map lower liminf, not a matching full-map upper. [Normality](theory/c2-hahn-normality.md), [simple lower](theory/c2-hahn-lower.md), [terminal rate](theory/c2-hahn-terminal-rate.md).
- The archive's returned H is monic; differently normalized retained bases do not imply a different returned matrix. Norm comparisons and executed fidelity checks are essential before linking NN conditioning to source errors. [Matrix norm theorem](theory/c1-matrix-metric.md), [source receipt](c4-source-receipt.json), [M2](c4-m2-bits-receipt.json).
- Complete finite native/external tables exist in both requested metrics, with bitwise shared inputs. External full-NN columns explicitly add H+d0 high-precision postprocessing. [Tables](c4-tables), [comparison receipt](c4-comparison-receipt.json).
- A-LU's finite accuracy is encouraging; a general weak-stability result is not proved. Input conditioning alone does not bound independent arithmetic residuals, and strict raw-array backward realizability remains a separate obstruction. [OPEN analysis](theory/c3-weak-stability-open.md).

No note should claim that every algorithm loses one digit per node, that a large kappa guarantees a particular rounding error, or that the paper's perturbation-based condition estimate equals our induced Jacobian norm. No contact with the authors has been made.
