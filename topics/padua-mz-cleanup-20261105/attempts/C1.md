directory and set PYTHONPATH to it. Example complete pipeline:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python topics/padua-mz-cleanup-20261105/code/g1_minimum.py --m 1240 --output /tmp/mz-replay/min.json --vector-dir /tmp/mz-replay/vectors
PYTHONPATH=/tmp/mz-cleanup-deps OPENBLAS_NUM_THREADS=1 python topics/padua-mz-cleanup-20261105/code/rigorous_witness.py --m 1240 --vector /tmp/mz-replay/vectors/m1240-n1239-min.npy --scratch /tmp/mz-replay/cert --output /tmp/mz-replay/producer.json

```
