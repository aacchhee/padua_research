## Actionable findings

1. **P2 — T4 drops the factor in the declared smoothed weight.** `translation.md:38–42` defines `w_n(x)=Delta_n(x)^(-1) integral_(x-Delta)^(x+Delta) w`, then says `w_n=1` for `w=1` and uses the same source constant C after deleting w_n. With the printed definition, w_n=2 away from boundary truncation and 1<=w_n<=2 under truncation. The displayed argument therefore establishes `lambda_- >= 1/(16 pi² M² C)`, rather than the claimed `1/(8 pi² M² C)`, if C really denotes the source constant as line 40 says. Fix by explicitly defining the specialized constant C to include `sup w_n`, or retain the factor 2. This is an exact normalization/proof defect, not a refutation of the qualitative small-ratio implication. It is independently visible in the submitted formulas and does not depend on accessing Mastroianni–Totik.

2. **P3 — T4 angular-gap orientation is reversed.** `translation.md:38` has `-1=x_0<...<x_S=1` and `x_j=cos xi_j`; with xi in [0,pi], xi decreases. Thus `xi_(j+1)-xi_j<=1/(Mn)` is vacuous and its converse lower-spacing condition impossible. Use absolute gaps or `xi_j-xi_(j+1)`. The CC specialization in line 42 already uses the intended positive gap pi/N. This is a definite misstatement in the submitted source summary; whether inherited from a source typographical convention was not verified.

3. **P3 — T5 should specify c and verify the endpoint hypothesis.** `translation.md:50` passes from `(1-|t_j|+c)^(2 sigma)` to `sin(theta_j)^(4 sigma)` without specifying c. The source's (1.31) requires `1-|t_j|+c >= tau delta_j` when b=1. At Lobatto endpoints delta_j is positive and of order N^-2, so c=0 fails; fixed positive c invalidates the asserted near-endpoint equivalence. The routine repair is `c=N^-2` (N>=2), L=1, and a fixed positive tau: at the endpoints delta=1-cos(pi/N), while at interior nodes delta=2 sin(theta)sin(pi/N). Then `1-|cos(theta_j)|+N^-2 asymp sin²(theta_j)` for interior j, and all quoted coefficient rates follow. Endpoint derivatives have magnitude 2N, so the endpoint coefficient is itself of order N^(-4 sigma), versus CC weight of order N^-2. The resulting ratio is N^(2-4 sigma), consistent with the stated interior obstruction. The qualitative borderline verdict survives.

Optional wording correction at line 22: norm and eigenvalue estimates do not have literally the “same comparison constants”; they have reciprocally squared constants (and log N vs 1+log N adds a bounded ratio for N>=2). T1 states the exact identity correctly.
