## Findings

**E6-R1 — low: correct the midpoint distribution separately for the triangle and deterministic grids.** Locations: record 50 lines 14 and 24; `directions/E6.md:25`; `e6_offsample.py:14`. The response correctly makes all errors sample-specific, but calls the midpoint density “triangular” for both random geometries and calls the T24/Q24 midpoint nodes iid uniform. For two iid uniform points on the square, the native midpoint has a product of two triangular densities (then rotate it). For the triangle, the density is an overlap area, hence piecewise quadratic, not triangular. In fact for `T={x,y>=-1,x+y<=0}` of area 2 and `Z=(X+Y)/2`, `f_Z(z)=area(T∩(2z−T))`; at `z=(-1+t,-1+t)`, `0<t<=1/2`, it is `4t²`. T24/Q24 and other deterministic benchmark midpoint sets have no iid sampling law. Retain the deterministic midpoint formula for every case, describe centre concentration only for the random cases, and restrict “product triangular density” to the rotated iid square. No output or numerical conclusion changes. This wording was inherited from audit-01's overgeneralization; it is not a failed numerical response.

**E6-R2 — low: NumPy below 2.5 is not a sufficient compatibility restriction.** Locations: `tracks/bivariate-lanczos/code/drift/README.md:110`, `external-code.md:17`, record 50 line 29, `directions/E6.md:64`, and IDEA-55's dependency sentence. The first 2.4.0 probe prompted the 2.4.1 check because 2.4.0 is yanked; the latter establishes this independently of that yanked release. The exact README installation pin `numpy==2.3.5` and the prescribed PYTHONPATH work. State that tested 2.3.5 is required for these reproductions and that 2.4.x already fails; do not present `<2.5` as the adequate ceiling. These isolated probes did not modify the working dependency installation or upstream code. I did not rerun a 2.5.x environment; its failure remains audit-01/response evidence.

**E6-R3 — low: reverse IDEA-57's kill criterion.** Location: `ideas-e6.md:69`. The candidate is “observed drift implies all fit problems fail,” but the kill criterion says a smooth target **losing** accuracy comparable to the worst-polynomial loss.
