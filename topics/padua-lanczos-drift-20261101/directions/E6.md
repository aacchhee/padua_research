## Claim, assumptions and limits

Actual unmodified polyrat 0.2.2 at commit `6903d7af9995c9d88e661fb229626696e00fdfba`, called with input coordinates `[y,x]`, gives the same floating-point columns as existing L2 dev plus full CGS2 on every reported case in this environment. Both have small Gram error while their span differs substantially from a well-conditioned polynomial reference on the frozen rotated squares and triangle. Consequently there exist degree-at-most-n polynomial data with nontrivial least-squares residual and off-sample error for this computed basis. This is an implementation measurement, not an impossibility theorem or a new stability proof. Fixed smooth targets (`exp(x+y)`, and one generic entire target added in response-01) remain accurately fit on those same non-product sets, to within the tested test distributions (see the response-01 section below); the worst-polynomial test error depends strongly on the test distribution.

Data and routines are the existing PD-N013/PD-N015/PD-T051 benchmark family: `L2.BENCH` unchanged, its original seeds, points, positive weights, and maximal degrees. Added frozen rational sets agree with E1: T24 = `{(i/12-1,j/12-1): i,j>=0,i+j<=24}`, M325; Q24 = `{((3x-4y)/5,(4x+3y)/5):x=i/12-1,y=j/12-1,0<=i,j<=24}`, M625. Each rational coordinate is formed exactly with Fraction and rounded once to double. E1-aligned n12 and additional n16 are both measured. They are not all-degree exact statements about the unrounded rational measure.

Comparators are actual upstream calls in two coordinate orders and existing own L2 full-CGS2 dev, mirror, alt, adapt (pivot). No two-relation method was added in this run. `adapt` chooses the greater residual/input norm after full CGS2, matching existing L2 implementation.

## Metrics and measured results

Let U be a Householder QR reference for the weighted evaluation space of all total-degree-at-most-n polynomials; let W be Householder QR of the computed basis. `gap = ||(I-WWᵀ)U||₂`, the largest sine of a principal angle for equal full dimensions. Orthogonality is `max|QᵀQ-I|`. Inverse-rotated product Chebyshev reference is used on rotated squares and Q24, Dubiner on triangle/T24. Other cases use box-scaled product Chebyshev. The normalized reference matrix's condition number, singular minimum, and numerical rank under `s0*max(M,N)*eps` are retained.

The adversarial target is selected **post hoc**, separately per case, as `f=Uv`, with v the leading right singular vector of `(I-P_upstream_yx)U`; its weighted training norm is one. Saved QR coefficients v permit reconstruction with the pinned input and reference code. This is a numerical representation of a polynomial in the reference span, subject to reported reference error; no exact symbolic polynomial certificate is claimed. The same target is fitted by every method. Training relative residual is `||(I-WWᵀ)f||₂/||f||₂` (denominator one), with direct `Q Qᵀ` residual also retained. For this adversarial target the training residual equals the gap **by construction** (`f=Uv`, v the leading right singular vector of `(I-WWᵀ)U`, so `||(I-WWᵀ)f||` is that singular value identically); the equality is not a finding, and the informative quantity is the off-sample error. Off-sample evaluation uses the actual upstream recurrence and least-squares coefficients from `np.linalg.lstsq`. Target off-sample values use the reference QR triangular solve.

The 128 test points are the explicit deterministic midpoints `(P[:128]+P[-128:])/2` of the node pairs `(P[i],P[-128+i])`. For the two hard cases the nodes are iid uniform in the support, so these midpoints are centre-concentrated, but the law differs by geometry: for the iid native square (rotpi4, in native coordinates before the rotation) the midpoint density is a product of two triangular densities; for the iid triangle `T={x,y>=-1,x+y<=0}` it is the overlap-area density `area(T∩(2z-T))`, piecewise quadratic and not triangular (for example `4t²` at `z=(-1+t,-1+t)`, `0<t<=1/2`). The T24/Q24 grids and the other deterministic benchmark node sets have no iid sampling law for their midpoints. **Every test error in the table below, and the `exp(x+y)` test errors, are specific to this midpoint distribution** (see the response-01 section for uniform interior and boundary-inclusive samples). These stay inside the convex triangle/square used for the main claims; for nonconvex annulus/L-shape they may lie outside the sampling domain. Test error is `||prediction-target||₂/||target||₂`. It is not a uniform norm or a generalization bound.

### References that do not certify the span

The complete suite was actually executed, including disk, L-shape, annulus, equispaced and cubic-clustered checkerboards. Reported reference κ is respectively 5.76e8, 1.11e15, 1.54e12, 3.83e8, 2.21e26. Numerical rank is 493/496 on L-shape, 495/496 annulus and 89/465 cubic. Their reported raw gaps are **not certified distances to the exact polynomial span**; no drift verdict is drawn from them here. Square n32 has κ4.14e5 and apparent gap5.6e-11, comparable to uκ4.6e-11, so no resolved square drift claim is made. Reference trust boolean is a diagnostic screen κ<1e8 plus full numerical rank, not a proof certificate; each error still needs comparison with its scale.

### Smooth-target practical distinction

The fixed target `exp(x+y)` was fit using the same actual upstream functions. Relative training and midpoint test errors on rot0.3/rotpi4/triangle are at most 2.2e-15, despite the worst-polynomial failures. This target is a ridge function aligned with the rotpi4 frame (there `x+y=sqrt(2)u` for the native square coordinate u, so it is univariate in the reference frame), and when it was chosen relative to the results is not documented in LOG or provenance; the word "independent" is therefore not supported by a chronology. Response-01 evaluates it off the midpoint set and adds one generic non-ridge target (below). Thus these measurements establish failure for certain polynomial directions, and no resolved loss of accuracy for the tested smooth targets (`exp(x+y)`, one generic entire target) under the three tested test distributions; they say nothing about other smooth functions. On cubic checkerboard n29, weighted training residual remains below 3e-16 but midpoint test relative error is about 5.07e9 (yx) /9.56e9 (xy); this severe off-sample conditioning phenomenon is reported separately, and its unusable reference prevents attributing it to a measured exact-space drift.

Observations (MEASURED, these two cases and these samples only):

- The adversarial test error depends strongly on the test distribution: the uniform-interior value is about 15 times the midpoint value for `[y,x]` on both cases (and larger than the gap `4.1e-3`, `1.0e-2` by factors 3.6 and 2.4). It is heavy-tailed and vertex-dominated: over ten disjoint 400-point blocks of the uniform sample the `[y,x]` error ranges from `7.0e-4` to `2.1e-2` (rotpi4) and from `2.2e-3` to `6.7e-2` (triangle). The midpoint value lies at or below the low end of those ranges. The `[x,y]` adversarial figures are for a target aimed at the `[y,x]` direction and are not the worst case for `[x,y]`.
- For `exp(x+y)` the upstream error grows from the midpoint to the boundary-inclusive sample by about a factor of 60 (rotpi4) and 20 (triangle) but stays at most `1.3e-13`, within a factor of about 3.5 of the reference-span least-squares error on the same samples (which itself grows to `4.0e-14`).
- For the generic target the upstream error equals the reference-span error to three digits on every sample, and the upstream prediction differs from the reference-span prediction by at most `5.0e-14` (uniform) and `3.7e-13` (boundary) relative to the target norm. Its error (1e-12 to 1e-8) is the approximation error of degree-n polynomials, so it is a weak probe of algorithmic loss; the audit-01 reviewer's independent run on rotpi4 with a different generic target `cos(3x+y)exp(y/2)` found test error `1.66e-13` against `4.6e-15` for the reference-span fit (audit-01 `E6-novelty-protocol.md`, run 10; not part of this developer's evidence).
- Orthogonality (E6-F3): `max|QᵀQ-I|=6.88e-15` is the (0,0) entry for upstream `[y,x]`, `[x,y]` and the reference factor on both cases; the off-diagonal maximum is `2.0e-16` and `2.5e-16` (rotpi4), `2.8e-16` and `2.1e-16` (triangle).

The qualitative conclusion (the drift is a worst-direction phenomenon; the tested smooth fits are not visibly harmed) is retained only as far as these numbers support it. The numerical value of any test error is specific to the sample.
