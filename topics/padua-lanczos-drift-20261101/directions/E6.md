## Claim, assumptions and limits

Actual unmodified polyrat 0.2.2 at commit `6903d7af9995c9d88e661fb229626696e00fdfba`, called with input coordinates `[y,x]`, gives the same floating-point columns as existing L2 dev plus full CGS2 on every reported case in this environment. Both have small Gram error while their span differs substantially from a well-conditioned polynomial reference on the frozen rotated squares and triangle. Consequently there exist degree-at-most-n polynomial data with nontrivial least-squares residual and off-sample error for this computed basis. This is an implementation measurement, not an impossibility theorem or a new stability proof. An independently fixed smooth target remains accurately fit on those same three non-product sets.

Data and routines are the existing PD-N013/PD-N015/PD-T051 benchmark family: `L2.BENCH` unchanged, its original seeds, points, positive weights, and maximal degrees. Added frozen rational sets agree with E1: T24 = `{(i/12-1,j/12-1): i,j>=0,i+j<=24}`, M325; Q24 = `{((3x-4y)/5,(4x+3y)/5):x=i/12-1,y=j/12-1,0<=i,j<=24}`, M625. Each rational coordinate is formed exactly with Fraction and rounded once to double. E1-aligned n12 and additional n16 are both measured. They are not all-degree exact statements about the unrounded rational measure.

Comparators are actual upstream calls in two coordinate orders and existing own L2 full-CGS2 dev, mirror, alt, adapt (pivot). No two-relation method was added in this run. `adapt` chooses the greater residual/input norm after full CGS2, matching existing L2 implementation.

## Metrics and measured results

Let U be a Householder QR reference for the weighted evaluation space of all total-degree-at-most-n polynomials; let W be Householder QR of the computed basis. `gap = ||(I-WWᵀ)U||₂`, the largest sine of a principal angle for equal full dimensions. Orthogonality is `max|QᵀQ-I|`. Inverse-rotated product Chebyshev reference is used on rotated squares and Q24, Dubiner on triangle/T24. Other cases use box-scaled product Chebyshev. The normalized reference matrix's condition number, singular minimum, and numerical rank under `s0*max(M,N)*eps` are retained.

The adversarial target is selected **post hoc**, separately per case, as `f=Uv`, with v the leading right singular vector of `(I-P_upstream_yx)U`; its weighted training norm is one. Saved QR coefficients v permit reconstruction with the pinned input and reference code. This is a numerical representation of a polynomial in the reference span, subject to reported reference error; no exact symbolic polynomial certificate is claimed. The same target is fitted by every method. Training relative residual is `||(I-WWᵀ)f||₂/||f||₂` (denominator one), with direct `Q Qᵀ` residual also retained. Off-sample evaluation uses the actual upstream recurrence and least-squares coefficients from `np.linalg.lstsq`. Target off-sample values use the reference QR triangular solve.

The 128 test points are deterministic midpoints `(P[:128]+P[-128:])/2`. These stay inside the convex triangle/square used for the main claims; for nonconvex annulus/L-shape they may lie outside the sampling domain. Test error is `||prediction-target||₂/||target||₂`. It is not a uniform norm or a generalization bound.

### References that do not certify the span

The complete suite was actually executed, including disk, L-shape, annulus, equispaced and cubic-clustered checkerboards. Reported reference κ is respectively 5.76e8, 1.11e15, 1.54e12, 3.83e8, 2.21e26. Numerical rank is 493/496 on L-shape, 495/496 annulus and 89/465 cubic. Their reported raw gaps are **not certified distances to the exact polynomial span**; no drift verdict is drawn from them here. Square n32 has κ4.14e5 and apparent gap5.6e-11, comparable to uκ4.6e-11, so no resolved square drift claim is made. Reference trust boolean is a diagnostic screen κ<1e8 plus full numerical rank, not a proof certificate; each error still needs comparison with its scale.

### Smooth-target practical distinction

Independent fixed target `exp(x+y)` was fit using the same actual upstream functions. Relative training and test errors on rot0.3/rotpi4/triangle are at most 2.2e-15, despite the worst-polynomial failures. Thus these measurements establish failure for certain polynomial directions, not broad loss of accuracy for ordinary smooth functions. On cubic checkerboard n29, weighted training residual remains below 3e-16 but midpoint test relative error is about 5.07e9 (yx) /9.56e9 (xy); this severe off-sample conditioning phenomenon is reported separately, and its unusable reference prevents attributing it to a measured exact-space drift.
