# Topic records

One topic is one working branch and one PR. Use [TOPIC_LOG.md](../templates/TOPIC_LOG.md), the stage rules in [WORKFLOW.md](../agents/WORKFLOW.md), and a descriptive topic slug.

Keep proposals, gate decisions, reports, audit-NN.md, response-NN.md and reproducible checks here. Put mathematical results in durable track theory files immediately; link them from the topic log. Preserve every generated candidate and each scoped rejection.
