## Cube-native LP (candidate IDEA?…-claude-03)

**Bound used.** For a positive rule exact on Π_{2n−1}, take G(x,y) of degree ≤ 2n−1 in each variable, with G ≥ 0 on cube², G(x,x) ≥ λK_{n−1}(x,x)² and ∫∫G = D. Then N ≥ λD. *Proof (orchestrator, plan.md §2; not yet in a theory record because nothing rests on it):*
- Σ_{ij} w_iw_jG(x_i,x_j) = ∫∫G, by exactness in each variable.
- Drop the off-diagonal terms, which are ≥ 0.
- Use Σ_i w_iK(x_i,x_i) = D, by exactness at degree 2n−2.
- Use Cauchy–Schwarz, Σp_i² ≥ D²/N.

**Measured** (`../evidence/lp-cube.json`; cut-plane LP, B3-symmetric):

Each cut-plane value is an upper bound for the LP. The constraints are imposed at finitely many points, so the relaxed optimum is ≥ the true optimum, up to floating-point error. Hence this LP cannot exclude a package at n = 3 or 4. The statement is MEASURED: there is no exact dual certificate of the upper bound.

**Heuristic, not a claim.** Averaging an interior blow-up of G over translations gives a positive-definite function with spectrum in 2O, i.e. a Turán-type problem without the Delsarte tail. This suggests that λ_n is governed asymptotically by T(int 2O)/|O|. The plain torus data are consistent with that value being 1. On this heuristic the observed λ ≈ 1.2 is a small-n boundary effect and should not be extrapolated. The localisation step is unproved.
