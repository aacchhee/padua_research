# L3 — Round R05 (started 2026-10-31T23:16+01:00): towards an explicit obstruction certificate for all Padua n ≥ 3

Developer: Claude Opus 5.5 (xhigh, requested). Working tree fba4d2f + R04 files.

## 1. Question

Construct C ⊥ Hankel (PD-T?…-309) with G_iᵀ C G_i ≻ 0 at all Padua nodes for every n ≥ 3, with a proof.

## 2. Derivation to be tested (written before the tests)

Parametrise C ⊥ Hankel by B_C(z,w) := Σ c_jk z^j w^k = (z − w)² K(z,w), K symmetric of bidegree ≤ (n−1, n−1) (a symmetric polynomial vanishing on the diagonal is divisible by (z−w)²; dimension n(n+1)/2 matches). Restrict to K(z,w) = κ(zw), κ(t) = Σ_{a=0}^{n−1} k_a t^a. At an interior Padua node (θ = jπ/n, φ = kπ/(n+1), x = cos θ, y = cos φ), PD-T?…-309(c) gives ∂_u q_m = −(s/2^{n−1})[A sin(mα) + B sin(mβ)] for m = 0..n+1 (α = θ+φ, β = θ−φ; (A, B) an invertible linear image of the direction u; the m = 0 and m = n+1 components match q_0, q_{n+1}). Writing sin(mγ) through e^{±imγ} and using B_C(z,z) = 0:
 uᵀ Hess p_C u ∝ p A² + q B² + 2rAB, p = −2κ(1) sin²α, q = −2κ(1) sin²β, r = 2[T R(θ) − S R(φ)],
 S = sin²θ, T = sin²φ, R(γ) := Σ_a k_a cos(2(a+1)γ),
so the interior Hessian is PD iff κ(1) < 0 and |κ(1)|·|S − T| > |T R(θ) − S R(φ)| (note sin α sin β = S − T ≠ 0 at interior nodes). For κ ≡ −1 the inequality is an equality (rank-one Hessians); for κ(t) = −(1 − c) − c t, R(γ) = −cos 2γ − c(cos 4γ − cos 2γ), and T R(θ) − S R(φ) = (S − T)(1 − 8c S T)·(sign conventions as in the test script), so the interior condition holds for 0 < c < 1/4 and every n ≥ 2.

## 3. Kill criteria (written before the tests)

- K10: if, for κ(t) = −(1 − c) − ct with c ∈ {0.1, 0.2}, the minimal Hessian eigenvalue over INTERIOR Padua nodes is ≤ 0 for some n ∈ [2, 12], the derivation of §2 is wrong and is withdrawn.
- K11: the candidate "this κ-family certifies ALL nodes" is killed if some BOUNDARY node has a non-PD Hessian for some n ∈ [3, 12] for both c values; then a boundary correction (K not a function of zw alone, e.g. terms in q_0 and q_{n+1}) is required.
