## 3. Consequences for the L3-Q1 verdict

The square-case verdict is node-set dependent: δ ≍ √ε when (H) holds (n = 1 always; Padua n = 2; equispaced checkerboards up to n = 5 numerically), obstruction when (H) fails robustly (Padua n = 3 exactly; Padua n = 4..7 and several random sets numerically). δ = O(ε) is impossible for every square set (PD-N?…-302, PROVED). The 1D Greenbaum width (√ε proven, as reported) matches the √ε rate of the (H) case; there is no 1D analogue of the obstruction (in 1D the square case has S_1 = {0}).
