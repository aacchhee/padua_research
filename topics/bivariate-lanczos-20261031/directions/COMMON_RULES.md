# Common round rules for all directions

- One round = one record `R<nn>.md` in the direction folder: question, attempt, result with claim-level status labels (PROVED / CONDITIONAL / MEASURED / OPEN), failed routes with specific obstructions, next question. ≤ 10 rounds (≤ 20 with written justification). Continue automatically while a concrete opening survives; stop when the direction is exhausted, a decisive negative result is reached, or the budget ends.
- Candidates: every new mechanism or claim gets a candidate record in `candidates.md` (template `templates/IDEA.md`, ID `IDEA?bivariate-lanczos-claude-Dnn` where D is the direction digit (L1→1, L2→2, L3→3, L4→4, L5→5)) with closest predecessor (registry entry or LIT key), separation criterion, kill test written *before* testing, result, disposition. Keep failed and equivalent ones.
- Durable results: each substantive claim in its own theory file under `tracks/bivariate-lanczos/theory/<descriptive-slug>.md` (template `templates/THEORY.md`, ID `PD-T?bivariate-lanczos-claude-Dnn`, negative mechanisms `PD-N?…-Dnn`). Split PROVED parts from OPEN/MEASURED ones. Proofs must be written out and checkable; label [EXACT], [FP], [IDEALIZED: …].
- Experiments: code in `tracks/bivariate-lanczos/code/L<D>/`, logs in `topics/bivariate-lanczos-20261031/directions/L<D>/logs/` (< 1 MB total), each run with command, seed, versions, output path. Floating point = MEASURED only. Never replace a failed guarantee with an experiment. Runs too large for 2 cores / 7 GB go to "Runs needed" in `R<nn>.md` with exact commands for AC's servers (syvert0/1/2).
- Literature: read `literature/INDEX.md` and the relevant `literature/records/*` before priority/attribution claims. A paywalled load-bearing source becomes "pending-reference", not a stop. AC's fulltexts (HL BIT/SIMAX 2002, Huhtanen 2002, BJ 1985, EGK 1991, Xu 1994, VB–C 2010) are at `/mnt/user-data/uploads/padua/papers/` — read them with pdftotext into the scratchpad only, never into the repo. You may use web search for open-access sources (arXiv etc.).
- No novelty claims; the independent adversarial reconstruction is a separate agent.
