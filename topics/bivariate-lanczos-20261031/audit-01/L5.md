`log(G/B) - log(H/B) = log(G/H)`.

With the same size weights, the slope difference is unchanged by this normalization. Positive separate ratio slopes are not a confidence interval for their difference. Independent reanalysis of the committed uniform-family data, using the record's own per-size means and t interval (seven sizes, df = 5), gives the paired Givens/HL slope **0.5953256, 95% interval [-0.1106994, 1.3013506]**. ### M2 — The prefix checker provides numerical estimates, not the claimed exact/certified singular-value enclosures

**Locations:** `tracks/bivariate-lanczos/theory/prefix-unisolvence-order-statistics-measured.md:12`, `:16`, `:22`, `:26`; `tracks/bivariate-lanczos/code/L5/prefix.py:45`, `:50`, `:65`, `:75`; repeated terminology in `exp_r01b.py` and R01/R03.

An SVD sets `lo == hi` and is called “exact”; hence these are not certified enclosures of the underlying real matrix. The additional claim that the constructed orthogonal Padua matrix has entry errors ≲ 3u is not a demonstrated bound. Against evaluation and column normalization on the same stored double nodes and weights, the checked entries at n = 10 and 62 differ by **3.32u and 3.62u**. These spot checks are themselves numerical, but show why a universal error enclosure cannot be inferred from “a few u.”

**Action:** consistently say “numerical lower/upper estimates,” “direct floating-point SVD,” and “smallest value among refined/scanned prefixes,” unless an error-enclosed calculation is supplied. Treat exact line-based singularity arguments separately from threshold classifications. A rigorous certification route would bound both matrix-construction and linear-algebra errors, with residual corrections, or use exact/interval arithmetic. Keep T503 and N506 MEASURED.

**Impact limit:** this does not invalidate the robust operational n = 50 counterexample: this audit obtains an all-prefix LU lower estimate **1.1564e-5**, with max-entry factorization residual **4.62e-15**. ## Mathematical reconstruction and status decisions

**T501 — accepted within scope.** For each stored nonzero pivot pair, hypothetical exact normalization produces an orthogonal plane rotation. The hypot/division assumptions give coefficient-vector error ≤ γ3. A two-term dot product adds ≤ √2 γ2(1+γ3), giving ε1. Applying the row and column stages gives joint Frobenius error ≤ θ Ξ with θ = √2 ε1(2+ε1). The recurrence `d_k ≤ (1+θ)d_(k-1)+θν`, together with `Rθ ≤ 1/2`, proves `d_R ≤ 2Rθν`. The same induction applies to w. Each index participates in at most M−1 rotations; total R ≤ M(M−1)/2. Data-dependent pivot choices do not alter the proof. The no-underflow/overflow and hypot assumptions matter. This proves proximity to a common orthogonal similarity, not the IEP zero pattern or forward accuracy, as the corrected text now says. The lemmas are routine proof steps, so PROVED for the file is appropriate; literature comparators and open interpretation are not part of the theorem.

**T505 — accepted.** A nonsingular prefix block B of a nonsingular full Vandermonde matrix has nonsingular Schur complement S. Its first column is nonzero; the determinant of each candidate bordered prefix equals `det(B) * s_l`. The largest candidate magnitude is at least `sigma_min(S)/sqrt(N-K)`. Induction includes K = 0 and K = N−1. Upper-triangular basis changes preserve all prefix minors; exact GEPP selects a nonzero Schur entry. No quantitative conditioning guarantee or floating-point GEPP certificate follows from this lemma. PROVED is appropriate.
