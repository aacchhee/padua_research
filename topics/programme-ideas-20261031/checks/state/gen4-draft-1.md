# Constrained equilibrium for discrete bivariate OPs: saturation on grids, no saturation on Padua
Model: claude-fable-5-1, effort xhigh · Angle D · 2026-10-31 (tests run 2026-10-31/11-01) · Status: returned (re-centred after the entry tests; see "Actual test results")

## Central question
For discrete orthonormal polynomials of total degree k = θn on an M-point planar node set with equal weights (equispaced (n+1)² grids as the saturating case; Padua / Chebyshev lattices as the non-saturating reference), what is the bivariate constrained extremal problem whose saturated set S_θ governs the Christoffel function, the block-Jacobi sections and the sup-norm growth ‖p‖_K/‖p‖_grid as n → ∞?

## Template theory
Univariate discrete-OP asymptotics in the saturated regime: for N nodes with asymptotic density σ and degree k ≍ θN, the zero counting measure converges to the minimizer of logarithmic energy under the constraint μ ≤ σ (Rakhmanov 1996; Dragnev–Saff 1997; Kuijlaars–Van Assche 1999; Kuijlaars–Rakhmanov 1999; strong asymptotics Baik–Kriecherbauer–McLaughlin–Miller 2007; all UNVERIFIED, from memory). Consequences: limits of recurrence coefficients; Kuijlaars's "which Ritz values converge" law (Numer. Math. 2000, UNVERIFIED); and for the equispaced n-grid the exact growth rate (1/n) log sup ‖p‖_{[−1,1]}/‖p‖_grid → C(α) = [(1+α)log(1+α)+(1−α)log(1−α)]/2 with saturated set [−1,−r]∪[r,1], r = √(1−α²) (Kuijlaars, JAT 288 (2023), web-checked 2026-10-31: univariate only, no multivariate statements). A bivariate version has to deliver: (i) the constrained extremal problem on [−1,1]² for *total-degree* polynomials (the logarithmic kernel is wrong in ℂ²; the natural object is a constrained pluripotential problem V_{K,σ} with obstacle σ, whose univariate degeneration is Rakhmanov's); (ii) identification of S_θ (the entry tests show it is a *corner* set on the equispaced grid, not a product strip); (iii) the Christoffel law λ_k(x) ≈ 1/(N_k·density) off S_θ versus λ_k(x) ≈ node weight on S_θ; (iv) the growth constant C_2(θ) (entry tests: numerically equal to the univariate C(θ)); (v) a joint-Ritz-value law for the sections (H_x^{(k)}, H_y^{(k)}) (entry tests: *no* joint convergence at any θ < 1, while H_x alone has converged Ritz values — a genuinely bivariate effect). The unconstrained side exists (Berman–Boucksom–Witt Nyström 2011 equidistribution; Berman–Ortega-Cerdà arXiv 1509.00956 necessary density for sampling, web-checked 2026-10-31: no sufficient conditions, no interpolation arrays, no constrained problem).

## Entry points and cheap decisive tests
1. **Saturation test (seconds).** s_k(B) := w_B K_k^{disc}(B,B) ∈ (0,1]; a node is saturated iff s_k(B) = 1. Compute on Pad_n (equal and cubature weights) and on the (n+1)² equispaced grid for θ ∈ {0.5, 0.75, 0.9}, n ≤ 60. Pre-written kill for Padua: fraction of nodes with s > 0.99 stays 0 for θ < 1 ⇒ no saturation on Padua (then Padua is only the reference case). Pre-written kill for the programme: if also on the equispaced grid no node saturates for θ ≤ 0.9, n ≤ 60, the constrained-equilibrium phenomenon is absent for total degree and the programme dies. **Outcome: Padua kill fires (0 nodes with s > 0.99, max s = 0.975 at θ = 0.95); grid does saturate (s(1,1) = 1.000 at θ ≥ 0.75, n ≥ 40; saturated fraction 0.6% at θ = 0.9, n = 60, confined to max-norm ≥ 0.967).** Programme survives on grids, Padua becomes the explicit reference.
2. **Growth-constant LP (minutes, n ≤ 24).** max p(x*,y*) s.t. |p| ≤ 1 on the grid, p ∈ Π_{θn}, via linprog over candidate (x*,y*) near the boundary; compare (1/n) log with the 1D value. Kill: if 2D/1D ratio → 2 (row-then-column bound sharp) the 2D problem is a trivial tensor consequence; if → 1 the theorem "C_2 = C_1" is the target. **Outcome: ratio 1.018 → 1.011 (θ = 0.5) and 0.999 (θ = 0.75) at n = 24.**
3. **Joint Ritz test (seconds, n ≤ 40).** Eigenvectors U of H_x^{(k)} + cH_y^{(k)} (random c); count joint residual pairs (‖H_xU−Uμ_x‖, ‖H_yU−Uμ_y‖ < 10⁻⁶) and compare with H_x-only convergence. Kill for sub-problem 4: if joint convergence tracks single-operator convergence, there is nothing bivariate to explain. **Outcome: joint converged = 0 everywhere (grid, Padua, random), H_x-only converged grows with θ** — a bivariate effect to explain.
4. **Christoffel-ratio control (seconds).** K^{disc}/K^{cont} must be 1 to 1e-14 for cubature weights, k ≤ n−1 (RES fact 1). **Outcome: passed (max |r−1| = 7e-15).**

## Why it is not an exclusion
- (a) 2-D Schur/Levinson: complexity of moments → OPs; here only n → ∞ limit laws, no complexity claim.
- (b) Finite-precision bivariate Lanczos (L1, L3, OBST-04): (b) studies O(u) rounding growth at fixed n governed by Ritz residuals; sub-problem 4 here is the exact-arithmetic limit law of joint Ritz values. Collapse observation: if LZ L1 proves the joint-Ritz limit as a lemma, sub-problem 4 is handed over; the rest stands.
- (c) Unisolvence over fields: unrelated.
- (d) MZ constants, nearest M3 (fixed-ratio η(θ) of the Gram matrix of the *continuous* basis under a discrete rule). Separation: our object is the discrete OP family and its saturated set; λ_min(G) in (d) is one scalar (the worst Christoffel ratio). Collapse: if M3 identifies S_θ as a by-product, sub-problem 2's measure-theoretic content becomes an M3 corollary and the candidate shrinks to 1, 3, 4.
- Already judged: "empirical Christoffel via QR" (QR is only the data generator here); "Uvarov reweighting" was judged narrow *as an algorithm* — here the rank-(2n+1) structure is an analytic tool for a theorem; "explicit Padua recurrences" are used as a benchmark, not claimed.

## Risks and obstructions
- Nearest recorded obstruction: LZ OBST-04 ("Padua sets have M = N, no long run of the recurrence"; hypothesis: finite precision, M ≫ N). Not applicable: exact-arithmetic limit law, and k = θn keeps N_k/M = θ² < 1.
- "Computed H_x, H_y never commute exactly": joint-eigenvalue extraction must be commutator-robust; in exact arithmetic irrelevant.
- Genuine risk 1 (realised): Padua does not saturate (MEASURED), so the Padua part is a reference theorem, not the core; the core lives on equispaced grids, where the connection to AC's Padua line is through the shared IEP machinery only.
- Genuine risk 2: the 2D growth constant equals the 1D one (MEASURED), so sub-problem 3 may be a short theorem rather than a paper on its own; it is bundled with Paper A.
- Genuine risk 3: a constrained pluripotential problem may have no tractable variational form; mitigation: the measured corner-first saturation suggests a one-parameter family of corner sets, testable against an ansatz before any theory.
