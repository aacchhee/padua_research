## Central question
Can a Riemann–Hilbert or Szegő-type (CMV/unit-circle) formulation be set up for the discrete product-Chebyshev measure on Padua points so that strong asymptotics of the recurrence blocks follow by a method rather than by the explicit closed form?

## Template theory
Deift et al. Riemann–Hilbert for OPs; Baik–Kriecherbauer–McLaughlin–Miller for discrete OPs (interpolation problem with poles at the nodes); Szegő theory / CMV (Simon). A bivariate version would need a matrix RH problem for the polyanalytic/normal-matrix formulation (N = X + iY) — none exists.
