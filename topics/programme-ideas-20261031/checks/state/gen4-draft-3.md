# Symmetric commuting extensions as the Gauss–Christoffel theory of bivariate cubature: lower bounds, uniqueness, Christoffel numbers
Model: claude-fable-5-1, effort xhigh · Angle D · 2026-10-31 (tests 2026-11-01) · Status: returned (with an ownership flag: Xu owns 2D constructions; the lower-bound/uniqueness/IEP side is not claimed by anyone found)

## Central question
Which positive cubature rules of degree 2n−1 on a planar domain correspond to *real symmetric* commuting extensions of the truncated block-Jacobi pair (H_x, H_y)|_{Π_{n−1}} of minimal size, and can the extension size, uniqueness and weights (Christoffel numbers) be read off the sections — giving sharper lower bounds than Möller's (Xu's 2025 open problem 1) and a structured inverse-eigenvalue algorithm for near-minimal rules?

## Template theory
Univariate Gauss–Christoffel theory: the n-point Gauss rule is the spectral decomposition of the n×n Jacobi section J_n; nodes = eigenvalues, weights = Christoffel numbers λ_n(x_j) = 1/K_{n−1}(x_j,x_j) = (first eigenvector component)²; the rule is unique, nodes interlace, Gauss–Radau/Lobatto are rank-1 modifications of J_n, Gauss–Kronrod is a (2n+1)-extension with a prescribed n-block (Laurie 1997), and "positive rule of degree 2n−1 with N nodes ⇔ Jacobi matrix of size N whose leading n-block is J_n" (the quadrature ↔ commuting-extension dictionary is trivial in 1D since one matrix always commutes with itself). Bivariate state: Mysovskikh/Xu: Gauss rules (N = dim Π_{n−1}) exist iff the sections commute, A_{n−1,1}A_{n−1,2}ᵀ = A_{n−1,2}A_{n−1,1}ᵀ (Xu 1994 Thm 2.4, rare); Möller: N ≥ dim Π_{n−1} + ½ rank[commutator] (Xu, Indag. Math. 2025 Thm 3.1, web-checked 2026-10-31), = dim Π_{n−1} + ⌊n/2⌋ for centrally symmetric weights; attainment iff nodes are common zeros of n+1−⌊n/2⌋ degree-n OPs (Thm 3.2); Degani–Schiff–Tannor (Numer. Math. 2005): cubature nodes ↔ joint eigenvalues of commuting extensions with a compatibility condition; Koiran (arXiv 2401.01302, Jan 2024, web-checked 2026-11-01): uniqueness and polynomial-time computation of commuting extensions of size r ≤ 4n/3 for ≥ 3 matrices, "wide open" for two matrices, no symmetric/positive version, no cubature results. What a bivariate Gauss–Christoffel theory must deliver: (i) the symmetric, positive-weight (first-row-squared) commuting-extension problem for *two* matrices as a structured IEP with its solution-set geometry; (ii) lower bounds on N that use symmetry and positivity (Möller uses only the commutator rank — MEASURED: Möller = dim + ½ rank for Chebyshev and Legendre, n ≤ 10, so the rank bound is exactly Möller's and anything sharper must use more structure); (iii) uniqueness/rigidity of near-minimal rules (two-matrix analogue of Koiran); (iv) Christoffel-number formulas for the weights (trivial for interpolatory rules: w_B = 1/K^{disc}(B,B); the nontrivial content is w_B as an explicit function of continuous kernels, e.g. Padua: w_B = 1/(K_n(B,B) − T_n(x_B)²), MEASURED to 2e-15, a direct consequence of the 2006 Lagrange formula).

## Entry points and cheap decisive tests
1. **Rank = Möller check (1 s).** Compute rank[H_x^{(n−1)}, H_y^{(n−1)}] for product Chebyshev/Legendre sections and compare dim Π_{n−1} + ½ rank with ½n(n+1) + ⌊n/2⌋. Kill for "rank bound is new": equality ⇒ the rank bound is Möller's (expected). **Outcome: equality for n = 2…10, both weights.** So sub-problem 2 must use positivity/symmetry, not rank alone.
2. **Extension existence/dimension (seconds–2 min).** Least squares for symmetric Möller-size extensions, random starts, Jacobian rank at solutions. Pre-written kill for sub-problem 1: if solutions never exist (residual > 1e-6 from all starts) the symmetric-extension formulation is empty; if they exist but are always isolated and inside the square, the geometry is trivial (then the content is only Paper B). **Outcome: solutions always found; positive-dimensional families for n ≤ 4; nodes outside the square for Chebyshev; isolated for Legendre n = 5, 6 (8/10 starts).** Non-trivial geometry.
3. **Padua Christoffel-number identity (1 s).** w_B·(K_n(B,B) − T_n(x_B)²) = 1 to machine precision. **Outcome: 4e-16…2e-15, n = 4…30.** (Trivial corollary of the Lagrange formula; serves as the exact benchmark for sub-problem 3.)
4. **Koiran hypothesis in 3D (1 s).** dim(Σ images) = 3·rank/2? **Outcome: true only at n = 2.**

## Why it is not an exclusion
- (a) 2-D Schur/Levinson: (a) is exact complexity for generic moment tables; the "Not flat at colength N" obstruction (EX-L1172, DST Thm 2, EX-T308) concerns *generic* two-level Hankel tables and Gorenstein extensions in algebraically closed fields. Here the tables are those of a *positive measure* (sections of a genuine commuting pair on an infinite-dimensional space), the extensions are real symmetric with positive first-row weights, and the question is approximation-theoretic (node counts, uniqueness), not complexity. Separation property: positivity + reality + minimal-size over ℝ. Collapse observation: if (a)'s T2 proves tight colength bounds for Gorenstein extensions that specialise to positive measures and give node-count lower bounds, Paper B becomes a corollary.
- "3D Padua via cubature / Li–Sun–Xu" exclusion and "Möller attainment beyond d = 2 EXCLUDED": sub-problem 2 does lower bounds only in d = 3; no 3D construction or attainment claim is made. Collapse observation: if the lower-bound work drifts into constructing 3D rules, it is out.
- (b), (c), (d): (c)'s PD-T003 is kernel/cubature over fields — we use only its real positive specialisation as benchmark; no finite-precision or MZ content.
- Already judged: "Moments → Jacobi as Prony" (F9): that is the forward map moments → sections; here the sections are given and we extend them — the inverse problem. "f(A,B) total-degree Krylov": not used. "Explicit Padua recurrences": benchmark only.
