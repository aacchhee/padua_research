# Structure theory of commuting generalized-Hessenberg pairs: minimal parametrizations, implicit-Q with order-ideal transitions, and core-transformation forms
Model: claude-fable-5-1, effort xhigh (as requested by the orchestrator) · Angle B · 2026-10-31 · Status: returned

## Central question
Do the commuting symmetric generalized-Hessenberg pairs (H_x, H_y) of a graded order (the degree-≤n sections of bivariate OP recurrences) admit a minimal, recurrence-compatible parametrization by O(N) "bivariate Jacobi parameters" — the pattern class has Θ(N^{3/2}) entries but the pairs form a family of dimension ≈ 4N (general measures) or 3N−1 (N-node discrete measures) — together with an implicit-Q theorem that stays valid across zero-pivot (order-ideal) transitions and a core-transformation (rotation-sequence) normal form for the unitary Q or, for nodes on the torus / normal case, for the condensed pair?

## Template theory
- Jacobi matrices (real line): the 2N−1 recurrence coefficients are free (Favard), the implicit-Q theorem gives uniqueness of the tridiagonalisation from the first column, and every operation on the measure (Christoffel, Geronimus, Uvarov, updating/downdating) is a local O(N) operation on the parameters (Gragg–Harrod; Elhay–Golub–Kautsky 1991; Gautschi).
- Unit circle: Schur/Verblunsky parameters; unitary Hessenberg = product of N−1 core transformations; CMV five-diagonal form; AMVW core-chasing calculus with fusion/turnover; Ammar–Gragg–Reichel downdating of Szegő polynomials; Humet Ch. 2 (JCAM 2014) does Christoffel/Geronimus as O(n) QR/RQ steps on the Givens factors.
- Multivariate Favard: Xu, Trans. AMS 342/343 (1994) and Dunkl–Xu Ch. 3: a pair of block Jacobi operators with full-rank A_{k,i} and the commutativity conditions is the recurrence of a quasi-definite functional; the conditions are quadratic matrix equations in (A, B). [UNVERIFIED from memory whether Dunkl–Xu count free parameters or give a canonical parametrization; the inputs record only that the block-Jacobi/Favard theory lives in the TAMS paper, pending-reference (LZ plan.md History).]
- What a bivariate version must deliver: (T1) a dimension theorem for the pattern-class commuting variety V_n (local dimension at a generic pair; singular locus = zero pivots); (T2) a recurrence-compatible chart: an ordered subset S of O(N) entries (or rotation angles) such that every other entry is a rational (ideally triangular, "chasable") function of S, with the order in which Algorithm 1 / HL compute them; (T3) implicit-Q: the pair is determined by the pattern, the start vector and S up to signs, and a statement of what replaces uniqueness when a pivot vanishes (the order ideal changes; the pattern is data-dependent; Humet's unproved "Generalised Implicit Q theorem" is this item in the vector-weight case, record humet-2019 / LZ 035); (T4) a core-transformation normal form: for the normal / torus case (nodes z ∈ C with Y = X̄, or |x|=|y|=1), the condensed pair as a product of cores in pattern layers with an Elsner–Ikramov-type uniqueness, so that the AMVW calculus (fusion, turnover, chasing) applies to the two-index case.

## Entry points and cheap decisive tests
1. **Jacobian-rank and variety-dimension test (seconds, n ≤ 6).** For random real nodes (M = N = 28, n = 6) and random positive weights, compute (H_x, H_y) by Householder QR of the graded monomial/Chebyshev Vandermonde (dense reference). Compute numerically the Jacobian J of the map (x_1..x_N, y_1..y_N, w_1..w_N) → (all pattern entries of H_x, H_y) by central differences (step 1e-6) and its numerical rank (gap criterion); expected 3N−1. Separately compute the tangent space of V_n at the pair: the null space of the linearised commutativity equations restricted to the pattern class, i.e. the dimension of {(E_x, E_y) in pattern, symmetric : [E_x, H_y] + [H_x, E_y] = 0}. Quantity: both ranks, for n = 3..6. **Kill criterion:** if dim T V_n ≫ 3N−1 by more than the count of degree-(n+1) boundary freedoms (≈ 2(n+1)(n+2)/2 entries of the last blocks, since the degree-n sections of an N-node measure do not see the top block) — concretely if dim T V_n > 3N−1 + (n+1)(n+2) at n = 6 — then the commuting pattern pairs are far from being parametrised by nodes and weights and the "3N–4N parameters" premise is wrong; the candidate is reduced to sub-problem 3 only. If dim T V_n < 3N−1 the map is not an immersion and the implicit-Q uniqueness premise is wrong (also a kill of sub-problem 2 as stated).
2. **Chart test (seconds, n ≤ 6).** Choose S = the entries that Algorithm 1 actually forms by a rotation (pivot columns: all of H_x's band plus one column of H_y per degree, as recorded in OBST-03; count |S|) and test whether the remaining pattern entries of H_y are determined by S through the commutativity equations: solve the linear system [H_x, H_y] = 0 for the unknown H_y entries given H_x and the S-columns of H_y; record rank deficiency. Then shrink S greedily (drop entries while the system stays uniquely solvable) to estimate the minimal chart size |S_min| at n = 3..6 and compare with 3N−1. **Kill criterion:** if |S_min| grows like N^{3/2} (fitted exponent ≥ 1.3 on n = 3..8) rather than like N, no minimal recurrence-compatible chart of entries exists and the programme keeps only sub-problem 3 (cores) and the uniqueness theorem.
3. **Zero-pivot test (seconds).** Harris–Simanek-type set with a non-unisolvent prefix (Padua points added column by column, n = 6) in Algorithm 1 with exact rational arithmetic (Fractions) to locate the zero pivot exactly; record which entries of the later pattern are forced and which are free after the pivot switch. Kill for the uniqueness statement at zero pivots: a case in which two different pivot choices give pairs that are NOT related by a signed permutation within the degree block (then the correct statement needs a different invariant and sub-problem 2 is harder than planned).
4. **Core-form test (normal case, seconds, N ≤ 36).** Nodes z_k ∈ C random, Y = X̄: run the HL-SIMAX ordering (cycles) and the seed's Algorithm 1 with pairs (z, z̄); count the rotations in the condensed form of the normal matrix N = Q^H diag(z) Q (Elsner–Ikramov bandwidth) and check whether N factors exactly as a product of cores in degree layers (compute the layers by peeling: at each layer, a sequence of Givens rotations annihilating one subdiagonal band of the condensed form; the residual after L layers should be upper triangular-plus-pattern). Kill: if the number of exact layers needed grows like N (i.e., no better than a general unitary) rather than like √N, there is no layered core form.

**Entry-point 1 was run (seconds; scratchpad `tangent_dim.py`, `tangent_dim2.py`; MEASURED in this scope only).** Random real nodes and weights, M = N, n = 3, 4, 5, 6; sections from Householder QR of the graded Chebyshev–Vandermonde; tolerance 1e-9 relative.
- Jacobian rank of (x, y, w) → (pattern entries of H_x, H_y) = 29, 44, 62, 83 = 3N−1 in all four cases (clear singular-value gap, ≈ 1e-2 / 1e-9).
- Tangent dimension of the commuting variety inside the **generalized-Hessenberg pattern actually produced** (pivot zeros included): 29, 44, 62, 83 = 3N−1, i.e. equal to the Jacobian rank. So, at a generic discrete-measure pair, the commuting generalized-Hessenberg pairs are locally exactly the sections of N-node measures modulo weight scaling: the premise of T1/T3 holds and the kill criterion did not fire.
- Tangent dimension inside the coarser **symmetric block-tridiagonal pattern** (no pivot zeros): 39, 64, 97, 139 = (3N−1) + C(n+2, 3) = (3N−1) + Σ_{k≤n} dim O(k+1), i.e. exactly the within-degree orthogonal gauge freedom. This is the discrete Favard count: generic commuting block-tridiagonal pairs with full-rank A-blocks are gauge-equivalent to sections of N-node measures.
- Consequence for the programme: sub-problem 1's dimension theorem is now a conjecture with four data points and an evident proof route (gauge-fixing by the pivot pattern + Favard); the first paper can lead with it.

**Entry-point 2, quick form, was run (seconds; scratchpad `chart_test.py`; MEASURED in this scope).** Random real nodes, n = 3, 4, 5, 6, 8. Given the full H_x (its generalized-Hessenberg pattern, Θ(N^{3/2}) entries), the symmetric pattern-class solutions E of [H_x, E] = 0 form a 3-dimensional space at every n (consistent with Huhtanen's "B is generically a polynomial in A": aI + bH_x plus one boundary freedom, UNVERIFIED as an identification). So H_y is determined by H_x and 3 numbers; the chart question is therefore entirely about H_x (and the degree-n boundary): whether its Θ(N^{3/2}) entries reduce to 3N−1 recurrence-compatible parameters. That is sharper than the test as written, and it is still open; the proxy "y-pivot columns" used in the quick run was uninformative (nearly every column qualifies) and the greedy chart-shrinking on H_x itself was not run.

## Risks and obstructions
Nearest recorded obstruction: "H_x, H_y never commute exactly in floating point" — this candidate's theory is exact (pairs that commute); its floating-point relevance is only through the chart's conditioning (sub-problem 4), stated as a mixed statement in the pattern class. Second: "Q not HSS-compressible" — not relied on; the core form is for the condensed pair, not Q, and only in the normal/torus case. Third: the possibility that Dunkl–Xu or Xu TAMS 1994 already contain the parameter count (then sub-problem 1 shrinks to the discrete-measure case and the chart question). Fourth: the symmetric real case has no unitary-Hessenberg structure, so "cores" may be the wrong representation there; the chart may be non-local (every entry depends on all of S), which would make it a theory result without an algorithmic payoff — test 2 decides.
