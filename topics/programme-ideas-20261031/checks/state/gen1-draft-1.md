# Bivariate Golub–Meurant: Gauss-type rules for bilinear forms of commuting pairs and normal matrices from the truncated bivariate recurrence
Model: claude-fable-5-1, effort xhigh (as requested by the orchestrator) · Angle A · 2026-10-31 · Status: returned

## Central question
Which bilinear forms uᵀf(X,Y)u (equivalently u*f(N,N*)u for a normal N = X+iY, or ∫f dμ for a discrete 2D measure) are reproduced exactly, bracketed, or boundably approximated by e₁ᵀ f(H_x^{(k)}, H_y^{(k)}) e₁ built from the k-th truncated sections of the bivariate recurrence (seed / Huhtanen–Larsen / Bartels–Jezioranski), and can the Golub–Meurant bordering templates (Gauss–Radau, Gauss–Lobatto, anti-Gauss, averaged, Kronrod-type) be realised on the non-commuting section pair?

## Template theory
Golub–Meurant "matrices, moments and quadrature" (Golub–Meurant 1994/2010; Golub–Welsch 1969; Laurie 1996 anti-Gauss, 1997 Kronrod; Gautschi; Calvetti–Reichel; Reichel–Spalević averaged rules). Key theorems: (i) k Lanczos steps give the k-point Gauss rule of the spectral measure of (A,u): e₁ᵀp(T_k)e₁ = uᵀp(A)u for deg p ≤ 2k−1; (ii) Gauss–Radau/Lobatto rules are obtained by bordering T_k with one modified row/column (prescribed node); (iii) anti-Gauss is T_{k+1} with the last off-diagonal scaled by √2, and Gauss/anti-Gauss bracket the integral and average to a (2k+1)-exact rule; (iv) Kronrod extension via Laurie's mixed-moment algorithm; (v) sign-definite error formulas give upper/lower bounds for uᵀf(A)u when f^{(2k)} has fixed sign (f = 1/z, e^z, log, …). Non-Hermitian relatives: Calvetti–Kim–Reichel SIMAX 2005 (Arnoldi rules exact for f(z)ḡ(z) with deg f ≤ n−1, deg g ≤ n; long recurrence) and Pozza–Pranić–Strakoš ETNA 2018 (quasi-definite functionals, non-Hermitian Lanczos).
A bivariate version has to deliver: (a) the exact class of "words" w(H_x^{(k)},H_y^{(k)}) (non-commuting sections) for which e₁ᵀw e₁ equals ∫x^a y^b dμ; (b) a positivity/error representation that replaces the single-variable kernel (the sections have no joint eigenvectors, so the rule is not a point rule in general — the gap between "matrix rule" and "cubature rule" is the whole point); (c) bordering constructions on the pair that preserve the exactness class and give brackets; (d) consequences for f(N) with N normal: bounds for u*f(N)u with f a function of z and z̄ (e.g. |z|^{−2}, e^{z}e^{z̄}, Gaussian in |z|², indicator-like functions) and for the HL SIMAX 2002 inclusion/exclusion regions, using O(√N)-window storage instead of Arnoldi's full basis.

## Entry points and cheap decisive tests
1. **Word-exactness census (seconds).** Random nodes M = 30, random positive weights, build exact (H_x,H_y) via QR of the graded Vandermonde, take sections k = 2..4 (N_k = (k+1)(k+2)/2 ≤ 15). For every word w in {x,y} of length ≤ 2k+1 compute |e₁ᵀw(H_x^{(k)},H_y^{(k)})e₁ − Σw_i x_i^a y_i^b|. Pre-written kill: if the x-first/y-last ordered words of total degree ≤ 2k−1 are *not* all exact to 1e-13, the Gauss template fails at the base and the programme reduces to sub-problem 3 only. Expected (conditional reasoning, not proved): with sections of degree ≤ k (size N_k = dim Π_k), every word of length ≤ 2k+1 in any order is exact, because e₁ᵀw₁w₂e₁ = ⟨w₁ᵀe₁, w₂e₁⟩ with lengths ≤ k and ≤ k+1, the first half is exact, and the truncation error of the second half lies in degree k+1, orthogonal to Π_k; words of length 2k+2 fail generically. If this holds, the "matrix rule" is exact on Π_{2k+1} with dim Π_k "nodes", which no point cubature can be (Möller bound) — this is the mechanism that separates the matrix rule from a cubature and is the first theorem of sub-problem 1. (Quantity to compute: the exactness set as a function of k.)
2. **Anti-Gauss sign flip (seconds).** Same data; form the (k+1)-section with the degree-k→k+1 coupling blocks scaled by √2 and compare the error on x^a y^b, a+b = 2k, 2k+1, with that of the k-section. Kill: if the errors do not have opposite sign on the degree-2k monomials for all tested orderings, the Laurie mechanism does not transfer by block scaling and sub-problem 2 needs a different bordering (record which).
3. **Bracket test on a normal matrix (seconds).** N = diag(nodes as complex numbers), u random, f(z) = 1/|z−c|² with c outside the node hull; compare Gauss/anti-Gauss values with the exact u*f(N)u for k = 2..6. Kill for sub-problem 3's bracketing claim: brackets fail on > 10% of random instances.
4. **Padua ground truth (seconds).** Use the closed-form sparse Padua sections (RES 2026-10-31 item 2) to check 1–2 against exact cubature sums, n ≤ 8.

## Plausible first paper (≈6 months)
"Gauss-type quadrature for bilinear forms of commuting Hermitian pairs via the truncated bivariate Lanczos recurrence": exactness theorem for ordered words (sub-problem 1), the anti-Gauss/averaged construction with a proof of the sign flip on a polynomial class (sub-problem 2, at least for product-type or symmetric measures), numerical comparison with Arnoldi rules on normal matrices (sub-problem 3 numerics). Reachable because all ingredients are finite-dimensional linear algebra on sections AC already computes; the only risk is that the sign-flip proof needs a Christoffel–Darboux-type identity for the pair, which exists in the literature (Xu 1993/1994; Fernández–Pérez–Piñar) in block form.

## Why it is not an exclusion
- (a) 2D Schur/Levinson: no moments→OP complexity, no exact-arithmetic exponent; sub-problem 4 uses exact arithmetic only as a prototype. Nearest item: none; the sections are given.
- (b) finite-precision bivariate Lanczos: nearest. Separation: (b) studies the *recurrence* (orthogonality loss, backward interpretation of Ĥ); this candidate studies the *functional* e₁ᵀf(sections)e₁ in exact arithmetic first (exactness, bracketing, bordering), which is a statement about the sections of the exact measure. Sub-problem 5 touches (b) and is explicitly subordinate; collapse observation: if the only interesting content turns out to be how rounding spoils exactness, the candidate is (b)'s.
- (c), (d): no unisolvence, no MZ constants. (d)'s M5 lists Radau/Lobatto *rules' MZ constants*; here Radau/Lobatto are *bordering constructions*.
- "Already judged": f(A,B) total-degree Krylov (R2 row 9, R3 §2) is nearest: judged weak because projected sections do not commute so f(H_A,H_B) is undefined beyond polynomials and tensorized Arnoldi wins for f(A,B)b. Separation: the object here is the *scalar* bilinear form, where exactness is a statement about e₁ᵀw e₁ for words and no f(H_A,H_B) needs defining (the rule is defined through the normal matrix Z = H_x+iH_y restricted appropriately, or through ordered words); the Huhtanen collapse (B = q(A), deg q ≤ M−1) does not reduce total-degree exactness to univariate Lanczos because deg q is not bounded in n. Collapse observation: if e₁ᵀw e₁ is exact only for words of x alone or y alone, there is no bivariate content and the candidate is the univariate Golub–Meurant applied twice.
- Measure modification/Uvarov (narrow): not touched.

## Risks and obstructions
- Nearest recorded obstruction: "Huhtanen 2002 collapse" (brief §3): commuting Hermitian A,B ⇒ B = q(A) generically, f(A,B)b reduces to univariate Lanczos; projected sections do not commute. Hypothesis: a functional calculus f(H_A,H_B) is needed. This candidate escapes because it never forms f of the sections jointly: exactness is a statement about ordered words/polynomials, and bracketing is about scalar errors; the degree of q grows with M so the univariate reduction gives no graded exactness.
- "Computed H_x, H_y never commute exactly": irrelevant in exact arithmetic; for sub-problem 5 the mixed formulation of (b) is the tool.
- Real risk: the sign-flip/bracketing theorems may hold only for restricted measure classes (product, centrally symmetric), leaving sub-problem 2 as a numerics paper. Second risk: the tensor anti-Gauss group (Cagliari) extends to non-tensor rules first (their stated ongoing work).
