### T3 — certified counting (tool paper)
Method (written before running): local maxima of λ_n(θ, φ) = Σ_B |L_B(cos θ, cos φ)| on the closed square, using the even 2π-periodic extension in angles so that edge and corner maxima are ordinary local maxima. Bounds used: M ≥ Λ_n from the Ehlich–Zeller mesh inequality on a (8n+1)² Chebyshev–Lobatto mesh (factor 1/cos²(π/16)); for any sign pattern σ the polynomial p_σ = Σ σ_B L_B satisfies |p_σ| ≤ Λ_n ≤ M, hence by Bernstein in each angle |∂p_σ| ≤ nM, |∂²p_σ| ≤ n²M, |∂³p_σ| ≤ n³M; the one-sided directional derivative obeys D_d⁺λ_n(x) ≥ ∇p_σ(x)·d for every σ consistent with x. Quadtree over [0, π]² (root split 32×32, max depth 14 ⇒ smallest half-width ≈ 6e-6). A box is certified EMPTY if, for every sign pattern consistent with some point of the box (B with |L_B(x_c)| ≤ 2 n M_B r may flip; M_B ≥ ‖L_B‖_∞ by the same mesh inequality), either (A) some direction d among the 8 axis/diagonal unit vectors has ∇p_σ(x_c)·d − √2 n²M·2r > 0, or (B) some d has D_dd p_σ(x_c) − 2 n³M·2r > 0 (strict convexity along lines through the box), or (C) the pattern is constant on the box, the Hessian of p_σ is negative definite on the box with margin, and the unique critical point of p_σ in the enclosing concave box lies in a sibling. A box is certified to contain EXACTLY ONE strict local maximum if the pattern is constant on it, H(x_c) ≼ −μ I with μ − 2 n³M·2r =: μ' > 0, and |∇p_σ(x_c)|/μ' < r (strong concavity ⇒ unique maximiser inside). Arithmetic: IEEE double; the minimal certificate margins are reported and must exceed 1e-8 (rounding bound for sums of ≤ 45 terms); a fully rigorous run would swap in interval arithmetic for the same evaluations.
