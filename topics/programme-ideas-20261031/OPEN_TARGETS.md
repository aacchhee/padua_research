Conventions used throughout. ### B3. δ-tolerant box counts on computed sections (complements PD-N?programme-ideas-claude-01)

**Setting** (revised, response-02, audit-02 B3). Fix n ≥ 1, N = dim Π_n.
- 𝒮_n(M), M > N: section pairs H = (H_x, H_y) of positive discrete measures on M nodes in [−1, 1]² whose support is Π_n-determining, in the graded orthonormal basis with positive leading coefficients (positive-pivot pattern pairs; e_1 cyclic). p(H) := the smallest pivot.
- 𝒞_n: commuting positive-pivot pattern pairs, i.e. the N-node section pairs (PD-T?programme-ideas-claude-01); non-empty for every n.
- Pair distance d(H, H′) := max(‖H_x − H′_x‖₂, ‖H_y − H′_y‖₂); δ(H) := ‖[H_x, H_y]‖₂.
- Box Q = (a, a′) × (b, b′); gap g(H, Q) := min( dist({a, a′}, spec H_x), dist({b, b′}, spec H_y) ), measured on the **computed** pair's marginal spectra.
- For H′ ∈ 𝒞_n, N_Q(H′) := number of joint eigenvalues of H′ in Q. Reference class 𝒩(H, Q) := {H′ ∈ 𝒞_n : d(H, H′) ≤ g(H, Q)/2}; by Weyl, every H′ ∈ 𝒩 has no marginal eigenvalue on the box boundary and the same marginal counts as H.
- n_box(H) is the symmetrised-product count of PD-N?programme-ideas-claude-01.

**Statement to decide, S(α).** There are α > ½ and a constant 0 < C = C(n, p) < ∞, both allowed to depend on n and on the pivot lower bound p > 0 (not on M, the nodes or the weights), such that for every M > N, every H ∈ 𝒮_n(M) with p(H) ≥ p and every box Q with **g(H, Q) > 0** and g(H, Q) ≥ C δ(H)^α: (i) 𝒩(H, Q) is non-empty; and (ii) N_Q(H′) takes one value on 𝒩(H, Q), equal to n_box(H). The condition g > 0 is required separately because δ(H) = 0 would otherwise admit g = 0, where the Weyl boundary-free consequence and the boundary-avoidance hypothesis of the commuting count (PD-N?…-01) fail. A stronger variant asks for one α working for all n and p. Variant S_F(α): the same with n_box replaced by a stated count object F computable from H. [PR preparation, audit-03 N2: g > 0, finite positive C and the dependence of α made explicit.]

**Negative form (a sufficient way to disprove S for fixed n and p, not its full logical negation).** For one fixed n and p > 0, a family H^(m) ∈ 𝒮_n(M_m) with p(H^(m)) ≥ p, 0 < δ(H^(m)) → 0, and boxes Q_m with boundary gap g(H^(m), Q_m) ≥ c δ(H^(m))^{1/2} for a fixed c > 0, such that (i) or (ii) fails for every m. Nothing here implies S(α) true or false. Done when: either a counterexample inside the computed-section class at distance ≈ c√δ (which would extend PD-N?…-01 to that class), or a theorem with α > ½ under stated hypotheses. Route for a counterexample: two nodes ε apart with M > N chosen so that the recurrence's sections inherit a 45° eigenbasis rotation in the cluster, with the box boundary gap of order √δ.
