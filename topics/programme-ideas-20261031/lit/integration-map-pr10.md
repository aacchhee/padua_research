# Literature integration map, second pass: programme-ideas baseline vs PR #10 rows (main 21e620b)

Prepared 2026-11-01 by a Sonnet helper for the Claude orchestrator. Companion file: `integration-map-pr10.json` (55 entries).

## Purpose

The first dedupe (`integration-map.json/.md`) compared the 111 provisional programme-ideas literature rows with main at 9739a0c. PR #10 (bivariate Lanczos) has since merged into main (21e620b) and added 227 final rows LIT-066..LIT-292 to `literature/INDEX.md`, many from sources that the programme-ideas baseline also cites. This pass re-checks the 55 baseline rows that share a source key with at least one new PR #10 row, so that rows stating a fact already recorded in PR #10 can be merged into that LIT ID rather than receive a new one.

## Method

- Input: the 55 entries with their full baseline row, the earlier relation, and every PR #10 INDEX row citing a shared source key.
- Each baseline statement was compared (content, hypotheses, locator, verification label) with each candidate row; where the INDEX row was too short the PR #10 record file under `literature/records/` was read (van Barel-Chesnokov 2010, Huhtanen-Larsen BIT 2002 and SIMAX 2002, Elhay-Golub-Kautsky 1991, Xu 1994, Zaccaron, Sauer, Humet, van Barel-Humet-Sorber, Faghih et al., Mourrain, Caliari et al., Hokanson, Zhu-Nakatsukasa, and others).
- A source-key sweep of INDEX.md found PR #10 rows missing from the supplied candidate lists (LIT-094, 105, 110 and others); they were added where they bear on the baseline row.
- `same`: the PR #10 row states the same published fact at the same or a compatible locator and our statement is contained in it (small extras are named in the note); the baseline row should be merged into that LIT ID. `overlap`: same source and related content, but ours is broader, adds a claim, spans several PR #10 rows, or differs in locator or hypotheses. `unrelated`: same source key, different content; treat as no PR #10 relation.
- Many baseline rows are composites that PR #10 split into several rows; these are `overlap` even when fully contained in the union, and the note says so.
- Conflicts record contradictory locators, hypotheses or wording, and cases where PR #10 holds a stronger reading than the baseline (or the reverse).
