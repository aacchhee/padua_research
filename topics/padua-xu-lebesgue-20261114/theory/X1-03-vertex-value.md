# PD-T?padua-xu-lebesgue-20261114-claude-03 — Exact Xu Lebesgue function at the non-node vertices: λ_n(v) = L_n²

ID kind: PD-T.
Aliases: X1-03; T1; vertex closed form; G2 closed form; Xu vertex value = square of the Chebyshev Lebesgue constant.
Split from: round X1-2 target T1 (closed form at the vertices, signs of every ℓ_ξ(v)).
Split into: none. The expansion is X1-07; the one-dimensional constant is X1-06.

## Statement

Let n ≥ 1. Let V* be the set of vertices of Q = [−1,1]² that are not Xu nodes: all four vertices if n is even, and {(1,−1), (−1,1)} if n is odd. Write a vertex as v = (z_{a_v}, z_{b_v}) with a_v, b_v ∈ {0, n}, and for a node ξ = (z_r, z_s) ∈ X_n put r′ = |r − a_v|, s′ = |s − b_v| (so r′ = r or n − r). Then for every v ∈ V* and ξ ∈ X_n:

**(a)** r′ + s′ is odd (in particular r′ ≠ s′), and

  ℓ_ξ(v) = w_ξ · (−1)^{r′} · (2 + z_{r′} + z_{s′}) / (z_{r′} − z_{s′}),  w_ξ = 2^{1−β(ξ)}/n²,   (1)

where β(ξ) is the number of coordinates of ξ equal to ±1. In particular ℓ_ξ(v) ≠ 0 and sign ℓ_ξ(v) = (−1)^{r′} sgn(s′ − r′).

**(b)** λ_n(v) = Σ_{ξ∈X_n} |ℓ_ξ(v)| = Σ_{ξ∈X_n} w_ξ (2 + z_{r′} + z_{s′}) / |z_{r′} − z_{s′}| = L_n², with L_n = (1/n) Σ_{k=1}^n cot((2k−1)π/(4n)).

For n odd, the other two vertices (1,1), (−1,−1) are nodes and λ_n = 1 there.

## Proof or evidence

**§1. Reduction to the origin of the lift grid.** Let v ∈ V* have angles (θ₁, θ₂) = (a_vπ/n, b_vπ/n) and put i = a_v + b_v, j = a_v − b_v, so that v = Φ(u_i, u_j). The four vertices give (i, j) = (0,0), (2n,0), (n,−n), (n,n) for (a_v, b_v) = (0,0), (n,n), (0,n), (n,0). A vertex is a node iff a_v + b_v ≡ n+1 (mod 2); so v ∈ V* iff i ≡ n (mod 2), and then j ≡ i ≡ n (mod 2): u_i and u_j are midpoints of C_n.

By X1-01 (1) and evenness of d_n, ℓ_ξ(v) = Σ_{(p,q)∈F(ξ)} d_n(u_{p−i}) d_n(u_{q−j}). Substitute p′ = p − i, q′ = q − j; these are odd residues mod 4n. Let O = (odd residues mod 4n)². The map (p, q) ↦ (p′, q′) is a bijection C_n² → O, and

 (p′+q′)/2 = (p+q)/2 − a_v, (p′−q′)/2 = (p−q)/2 − b_v (mod 2n).

Since a_v, b_v ∈ {0, n}, the node ξ = (z_r, z_s) below (p, q) corresponds to the pair (r′, s′) = (|r − a_v|, |s − b_v|) in the sense that (p′+q′)/2 ≡ ±r′ and (p′−q′)/2 ≡ ±s′ (mod 2n). Moreover r′ + s′ ≡ (p′+q′)/2 + (p′−q′)/2 = p′ ≡ 1 (mod 2). Hence

  ℓ_ξ(v) = Σ_{(p′,q′) ∈ F′} d_n(u_{p′}) d_n(u_{q′}),  F′ = {(p′, q′) ∈ O : (p′+q′)/2 ≡ ±r′, (p′−q′)/2 ≡ ±s′ (mod 2n)}.   (2)

F′ is an orbit of the group generated by τ, s, c acting on O (same argument as X1-01 §1), |F′| = |F(ξ)| = 2^{3−β(ξ)}, and (p₀, q₀) := (r′+s′, r′−s′) ∈ F′.

**§2. Evaluation of (2).** Put t(p′, q′) = d_n(u_{p′}) d_n(u_{q′}). Since F′ is one orbit of a group of order 8, Σ_{F′} t = (|F′|/8) Σ_{γ∈Γ} t(γ(p₀, q₀)). The elements 1, s, c, sc map (p₀, q₀) to (±p₀, ±q₀) or (±q₀, ±p₀) with equal signs, and d_n is even, so each of them gives t(p₀, q₀). The other four elements give t(p₀+2n, q₀+2n). With α = p₀π/(4n), β̃ = q₀π/(4n) and d_n(u_m) = sin(mπ/2)cot(mπ/(4n))/(2n) for odd m (X1-02 (b)):

 t(p₀, q₀) = sin(p₀π/2) sin(q₀π/2) cot α cot β̃ /(4n²),
 t(p₀+2n, q₀+2n) = sin(p₀π/2 + nπ) sin(q₀π/2 + nπ) (−tan α)(−tan β̃)/(4n²) = sin(p₀π/2) sin(q₀π/2) tan α tan β̃ /(4n²).

Here 1 ≤ p₀ = r′+s′ ≤ 2n−1 and 1 ≤ |q₀| = |r′−s′| ≤ n, so α ∈ (0, π/2) and β̃ ∈ [−π/4, π/4] ∖ {0}: all four cotangents and tangents are finite and nonzero. Therefore

 ℓ_ξ(v) = (|F′|/(8n²)) · sin(p₀π/2) sin(q₀π/2) · (cot α cot β̃ + tan α tan β̃).

Two elementary identities finish the computation.
- sin(p₀π/2) sin(q₀π/2) = ½[cos((p₀−q₀)π/2) − cos((p₀+q₀)π/2)] = ½[(−1)^{s′} − (−1)^{r′}] = −(−1)^{r′}, because r′ + s′ is odd.
- cot α cot β̃ + tan α tan β̃ = (cos²α cos²β̃ + sin²α sin²β̃)/(sin α cos α sin β̃ cos β̃) = 2(1 + cos 2α cos 2β̃)/(sin 2α sin 2β̃). With a′ = 2α + 2β̃ = r′π/n and b′ = 2α − 2β̃ = s′π/n: 2cos 2α cos 2β̃ = cos a′ + cos b′ = z_{r′} + z_{s′} and 2 sin 2α sin 2β̃ = cos b′ − cos a′ = z_{s′} − z_{r′}. So the sum equals 2(2 + z_{r′} + z_{s′})/(z_{s′} − z_{r′}).

Multiplying: ℓ_ξ(v) = (|F′|/(4n²)) (−1)^{r′} (2 + z_{r′} + z_{s′})/(z_{r′} − z_{s′}), and |F′|/(4n²) = 2^{1−β(ξ)}/n². This is (1). The numerator 2 + z_{r′} + z_{s′} is positive (not both cosines are −1 because r′ ≠ s′), and z_{r′} − z_{s′} > 0 iff r′ < s′, which gives the sign. ∎(a)

**§3. The sum.** Every term of (2) is nonzero and has the same sign: by §2 the two values t(p₀, q₀) and t(p₀+2n, q₀+2n) have the common sign factor sin(p₀π/2)sin(q₀π/2) times cot α cot β̃, resp. tan α tan β̃, and these two products have the same sign. Hence |ℓ_ξ(v)| = Σ_{F′} |t| = Σ_{(p,q)∈F(ξ)} |d_n(u_i − u_p)| |d_n(u_j − u_q)|. Summing over ξ and using that the fibers partition C_n² (X1-01 (a)):

 λ_n(v) = Σ_{(p,q)∈C_n²} |d_n(u_i − u_p)| |d_n(u_j − u_q)| = ω_n^{C_n}(u_i) · ω_n^{C_n}(u_j) = L_n²

by X1-02 (b), since u_i and u_j are midpoints of C_n. The middle expression in (b) is Σ_ξ |ℓ_ξ(v)| with (1) inserted. For n odd, (1,1) = (z_0, z_0) and (−1,−1) = (z_n, z_n) are nodes (0 + 0 and n + n are even = n+1 mod 2), so λ_n = Σ_ξ |δ_{ξ,v}| = 1 there. ∎
