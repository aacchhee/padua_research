# Topic results files

There is one file per topic, `results/<topic-slug>.md`, written only by that topic's orchestrator on its topic branch. The rule is in `agents/WORKFLOW.md`, under Computation and evidence. Each file lists the topic's meaningful results, with status, IDs and links to their durable records, plus the current next step. The repository-root `RESULTS.md` is the merged view, with one section per topic, which each topic updates in its own PR at PR preparation.
