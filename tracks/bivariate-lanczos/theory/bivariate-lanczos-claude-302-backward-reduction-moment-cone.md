## Statement

Notation: nodes z_1..z_M, weights w_i > 0, μ = Σ w_i δ_{z_i}, m := L_μ(1), with M_n(L_μ) ≻ 0 (nodes Π_n-unisolvent). V := Π_{2n+1}, V* its dual with a fixed norm ‖·‖ and the dual norm ‖·‖_* on V. K_δ := ∪_i B̄(z_i, δ) (closed Euclidean balls). C(K) := closed convex cone in V* generated by {ev_z : z ∈ K}; Pos(K) := {p ∈ V : p ≥ 0 on K}. Φ, 𝒞_n as in PD-T?…-301. H_0 := {E ∈ V* : E(1) = 0}. ε_1 > 0 is such that M_n(L_μ + E) ≻ 0 whenever ‖E‖ ≤ ε_1. Throughout (b), 0 ≤ θ < 1.

(a) [Exact form.] For Ĥ ∈ 𝒞_n with L̂ := Φ^{-1}(Ĥ), the following are equivalent: (i) there is a positive (atomic) measure μ′ supported in K_δ whose exact degree-n sections equal Ĥ; (ii) L̂ ∈ C(K_δ); (iii) L̂(p) ≥ 0 for all p ∈ Pos(K_δ); (iv) L̂ admits a positive cubature formula of degree 2n+1 with all nodes in K_δ. When they hold, μ′ can be taken with at most dim Π_{2n+1} atoms.

(b) [All perturbations of a given size — three consistent residual conventions (Definitions); each threshold holds only in its own convention.]

(b1) [Functional perturbations given as data; unnormalised residual (R1).] Define r(δ) := min{ L_μ(p) : p ∈ Pos(K_δ), ‖p‖_* = 1 }. Then B(L_μ, ε) ⊂ C(K_δ) iff r(δ) ≥ ε. If r(δ) < ε, a minimiser p gives an E with ‖E‖ = ε and dist(L_μ + E, C(K_δ)) ≥ ε − r(δ). Residual form, measured against the functional L_μ + E itself with approximants of any mass: if r(δ) ≥ (1−θ)ε, then dist(L_μ + E, C(K_δ)) ≤ θ‖E‖ ≤ θε for every E with ‖E‖ ≤ ε; if r(δ) < (1−θ)ε, some E with ‖E‖ = ε has dist(L_μ + E, C(K_δ)) > θε. Exact representation (invariant under positive scaling): r is nondecreasing in δ; with δ*(ε) := inf{δ : r(δ) ≥ ε} and ε ≤ ε_1, for δ > δ*(ε) every consistent perturbation Ĥ = Φ(L_μ + E), ‖E‖ ≤ ε, is the exact section pair of a positive measure on K_δ, and for δ < δ*(ε) some such perturbation is not.

(b2) [Mass-preserving perturbations; fixed-mass residual (R2).] Let |p|_0 := min_{t ∈ ℝ} ‖p − t‖_* (= max{E(p) : E ∈ H_0, ‖E‖ ≤ 1}) and r_0(δ) := inf{ L_μ(p)/|p|_0 : p ∈ Pos(K_δ), p ∉ ℝ·1 }.
 (i) {L_μ + E : E ∈ H_0, ‖E‖ ≤ ε} ⊂ C(K_δ) iff r_0(δ) ≥ ε.
 (ii) If r_0(δ) ≥ (1−θ)ε, then for every E ∈ H_0 with ‖E‖ ≤ ε there is a positive measure μ′ on K_δ with μ′(ℝ²) = m and ‖L_{μ′} − (L_μ + E)‖ ≤ θε (and M_n(L_{μ′}) ≻ 0 if ε ≤ ε_1). If r_0(δ) < (1−θ)ε, there is E ∈ H_0 with ‖E‖ ≤ ε such that ‖L_{μ′} − (L_μ + E)‖ > θε for every positive measure μ′ on K_δ with μ′(ℝ²) = m.
 (iii) r(δ) ≤ r_0(δ) and r(δ) ≥ r_0(δ)/(A + B r_0(δ)), with A := 1 + ‖1‖_* max_i ‖ev_{z_i}‖ and B := ‖1‖_*/w_min (w_min := min_i w_i). Hence r(δ) = 0 iff r_0(δ) = 0, and r(δ) ≍ r_0(δ) as either tends to 0, so r and r_0 have the same rates (PD-T?…-303).

(b3) [Section data normalised to mass m; the factor is carried (R3).] For ‖E‖ ≤ ε < m/‖1‖_*, the mass-m representative of the section pair Φ(L_μ + E) (when Φ is defined, i.e. M_n(L_μ + E) ≻ 0, e.g. for ε ≤ ε₁) is L̂ = s_E (L_μ + E), s_E := m/(m + E(1)) ∈ [m/(m + ε‖1‖_*), m/(m − ε‖1‖_*)], and dist(L̂, C(K_δ)) = s_E · dist(L_μ + E, C(K_δ)) (approximants of any mass). Hence: if r(δ) ≥ (1−θ)ε, then dist(L̂, C(K_δ)) ≤ θε·m/(m − ε‖1‖_*) for every ‖E‖ ≤ ε; if r(δ) < (1−θ)ε, the E of (b1) has dist(L̂, C(K_δ)) > θε·m/(m + ε‖1‖_*). The factor cannot be replaced by 1: the implication "r(δ) ≥ (1−θ)ε ⇒ dist(L̂, C(K_δ)) ≤ θε" is false in general (PD-N?bivariate-lanczos-claude-309, exact counterexample).

(b4) [Section norms — routine.] Fix a norm on section pairs and put Ψ(Ĥ) := m Φ^{-1}(Ĥ) − L_μ ∈ H_0. There are η_0, c_1, c_2 > 0 (depending on z, w, n and the norms) with ‖Ψ(Ĥ)‖ ≤ c_2 ‖Ĥ − Φ(μ)‖ for Ĥ ∈ 𝒞_n, ‖Ĥ − Φ(μ)‖ ≤ η_0, and ‖Φ(L_μ + E) − Φ(μ)‖ ≤ ‖E‖/c_1 for E ∈ H_0, ‖E‖ ≤ c_1 η_0. Consequently, for η ≤ η_0: if r_0(δ) ≥ c_2 η, every Ĥ ∈ 𝒞_n with ‖Ĥ − Φ(μ)‖ ≤ η is the exact section pair of a positive measure on K_δ; if r_0(δ) < c_1 η, some Ĥ ∈ 𝒞_n with ‖Ĥ − Φ(μ)‖ ≤ η is not. No exact constant is claimed in section norms.

(c) [Literal reading under an added forward-accuracy hypothesis — routine.] The frozen hypothesis does not by itself tie Ĥ to the nodes. Read with relations on the sections alone (interior commutativity), the literal question is trivially NEGATIVE (Ĥ = Φ(ν) for a positive ν far from the nodes satisfies every relation exactly); read with the local relations of the computed basis it is the Greenbaum regime (G), OPEN. Only under the added hypothesis that the data are forward-accurate is it trivially positive: ‖Ĥ − Φ(μ)‖ ≤ ε, then μ′ = μ (δ = 0) satisfies "exact sections of μ′ = Ĥ up to O(ε)" with constant 1. Hence L3-Q1 has content only (1) in the exact form (a)/(b) (residual strictly smaller than the perturbation), or (2) in the non-perturbative (loss-of-orthogonality) regime where Ĥ is far from Φ(μ) but satisfies the local relations up to O(ε) (Greenbaum regime; OPEN, target file 300).

(d) [Inconsistent data.] If Ĥ is structured and within η of 𝒞_n (interior commutativity / consistency relations violated by O(η)), then a point of 𝒞_n within C η exists (local projection; C depends on (z, w, n)); (a)/(b) apply to it, with an additional residual O(η). The same holds for the partial (computed-entries) data of PD-T?…-301(d).

## Definitions

"Exact degree-n sections of μ′" = Φ(L_{μ′}), requiring M_n(L_{μ′}) ≻ 0 (automatic in (a)). "Supported within distance δ" means supp μ′ ⊂ K_δ (support inclusion, not Hausdorff distance). In the square case the existence results of PD-T?…-303 also give Hausdorff distance ≤ δ for small ε: pairing L_{μ′} with ℓ_i² (ℓ_i the Π_n Lagrange basis at the nodes) shows that each ball carries mass w_i + O(δ + ε) > 0; in the overdetermined case with δ = 0 all node weights are w_i + O(ε) > 0.

Residual conventions (finding LF-M1 of Codex audit-01). A residual is a functional-norm distance ‖L_{μ′} − L_ref‖ between the moment functional of a positive measure μ′ on K_δ and a reference functional L_ref representing the data:
- (R1) functional perturbations E given as data; L_ref := L_μ + E itself (no renormalisation); μ′ of any mass — used in (b1).
- (R2) mass-preserving perturbations E ∈ H_0; L_ref := L_μ + E (mass m); μ′ of mass m — used in (b2).
- (R3) section data Ĥ; L_ref := L̂ := m Φ^{-1}(Ĥ), the representative of mass m; μ′ of any mass — used in (b3), where the threshold carries the factor s_E.
A free scale c > 0 on the reference (‖L_{μ′} − c L̂‖ ≤ θε for some c) is never allowed: it would make every residual trivially small (μ′ = cμ, c → 0; finding M2 of L3-reconstruction-01). For E ∈ H_0 the references of (R1) and (R3) coincide (s_E = 1); (R2) differs from them only in the mass constraint on μ′. Exact representation (θ = 0, (a)) is the same in all three conventions, because C(K_δ) is a cone.

## Assumptions

[EXACT]; [IDEALIZED: perturbations given as data] for (b): in (b1) and (b3), E ranges over all functionals with ‖E‖ ≤ ε; in (b2), over E ∈ H_0 with ‖E‖ ≤ ε. ## Proof or evidence

(a) (i)⇒(ii): Φ(L_{μ′}) = Ĥ = Φ(L̂) ⇒ L_{μ′} = c L̂, c = μ′(K) > 0 (PD-T?…-301(b) uniqueness), and L_{μ′} ∈ C(K_δ). (ii)⇒(i): K_δ is compact and ev_z(1) = 1, so {ev_z : z ∈ K_δ} is a compact set whose convex hull misses 0; its conic hull is closed and equals the set of finite nonnegative combinations; by Carathéodory any element is a combination of ≤ dim V point evaluations: L̂ = Σ λ_j ev_{ξ_j}, λ_j > 0, ξ_j ∈ K_δ. Then μ′ := Σ λ_j δ_{ξ_j} has L_{μ′} = L̂, so M_n(L_{μ′}) = M_n(L̂) ≻ 0 and Φ(μ′) = Ĥ. (ii)⇔(iii): the dual cone of C(K_δ) is Pos(K_δ) and C(K_δ) is a closed convex cone (bipolar theorem). (iv) is (ii) restated (nodes ξ_j, weights λ_j).

(b1) For a closed convex cone C with dual C*, B(L, ε) ⊂ C iff L(p) + E(p) ≥ 0 for all p ∈ C*, ‖E‖ ≤ ε, iff L(p) ≥ ε‖p‖_* for all p ∈ C*. With C* = Pos(K_δ) this is r(δ) ≥ ε. The minimum defining r(δ) exists (compact intersection of a closed cone with the unit sphere). If r(δ) < ε with minimiser p (‖p‖_* = 1), choose E with ‖E‖ = ε, E(p) = −ε (a norming functional, finite dimensions); then for every L′ ∈ C(K_δ): ‖L′ − L_μ − E‖ ≥ (L′ − L_μ − E)(p) ≥ 0 − r(δ) + ε. Residual form: if r(δ) ≥ (1−θ)ε and ‖E‖ ≤ ε, then ‖(1−θ)E‖ ≤ r(δ), so L′ := L_μ + (1−θ)E ∈ C(K_δ) and ‖L′ − (L_μ + E)‖ = θ‖E‖ ≤ θε. If r(δ) < (1−θ)ε, the E just constructed has dist(L_μ + E, C(K_δ)) ≥ ε − r(δ) > θε. Exact representation: for ‖E‖ ≤ ε ≤ ε_1, Φ(L_μ + E) is defined and, by (a) and invariance of Φ and of the cone under positive scaling, it is the exact section pair of a positive measure on K_δ iff L_μ + E ∈ C(K_δ). K_δ ⊂ K_{δ′} for δ ≤ δ′ gives Pos(K_{δ′}) ⊂ Pos(K_δ), so r is nondecreasing; for δ > δ*(ε) there is δ′ ∈ [δ*(ε), δ) with r(δ′) ≥ ε, hence r(δ) ≥ ε and B(L_μ, ε) ⊂ C(K_δ); for δ < δ*(ε), r(δ) < ε and the E above (‖E‖ = ε ≤ ε_1) gives L_μ + E ∉ C(K_δ).

(b2) Duality: for E ∈ H_0 and every t, E(p) = E(p − t) ≤ ‖E‖ ‖p − t‖_*, so E(p) ≤ ‖E‖ |p|_0; conversely H_0 is the annihilator of ℝ·1, which is isometrically the dual of V/ℝ·1 with the quotient norm, so (finite dimensions) some E ∈ H_0 with ‖E‖ ≤ 1 has E(p) = |p|_0, and the minimum over t is attained. Constants have |t|_0 = 0, and p ↦ |p|_0 vanishes only on ℝ·1.
(i) If r_0(δ) ≥ ε, E ∈ H_0, ‖E‖ ≤ ε and p ∈ Pos(K_δ): for p ∉ ℝ·1, (L_μ + E)(p) ≥ L_μ(p) − ε|p|_0 ≥ 0; for p = t ≥ 0, (L_μ + E)(p) = m t ≥ 0. Since C(K_δ) is closed with dual cone Pos(K_δ) (proof of (a)), L_μ + E ∈ C(K_δ). If r_0(δ) < ε, pick p ∈ Pos(K_δ) \ ℝ·1 with L_μ(p) < ε |p|_0 and E ∈ H_0 with ‖E‖ ≤ ε and E(p) = −ε|p|_0; then (L_μ + E)(p) < 0, so L_μ + E ∉ C(K_δ).
(ii) If r_0(δ) ≥ (1−θ)ε and E ∈ H_0, ‖E‖ ≤ ε: by (i) applied to (1−θ)E, L′ := L_μ + (1−θ)E ∈ C(K_δ), i.e. L′ = L_{μ′} for a positive atomic μ′ on K_δ (proof of (a)); μ′(ℝ²) = L′(1) = m, ‖L_{μ′} − (L_μ + E)‖ = θ‖E‖ ≤ θε, and ‖L_{μ′} − L_μ‖ ≤ ε ≤ ε_1 gives M_n(L_{μ′}) ≻ 0. If r_0(δ) < (1−θ)ε, pick p ∈ Pos(K_δ) \ ℝ·1 with |p|_0 = 1 and L_μ(p) < (1−θ)ε, and E ∈ H_0 with ‖E‖ ≤ ε and E(p) = −ε. For every positive μ′ on K_δ with μ′(ℝ²) = m, D := L_{μ′} − L_μ − E lies in H_0, so ‖D‖ ≥ D(p)/|p|_0 = L_{μ′}(p) − L_μ(p) + ε > 0 − (1−θ)ε + ε = θε.
(iii) By homogeneity r(δ) = min{L_μ(p)/‖p‖_* : p ∈ Pos(K_δ) \ {0}}. For p ∈ Pos(K_δ) \ ℝ·1, |p|_0 ≤ ‖p‖_* gives L_μ(p)/‖p‖_* ≤ L_μ(p)/|p|_0, so r(δ) ≤ r_0(δ). Lower bound: normalise |p|_0 = 1 and let t_0 attain min_t ‖p − t‖_*. For every node, |p(z_i) − t_0| ≤ ‖ev_{z_i}‖ ‖p − t_0‖_* = ‖ev_{z_i}‖, and 0 ≤ p(z_i) ≤ L_μ(p)/w_min (all p(z_j) ≥ 0, z_j ∈ K_δ); hence |t_0| ≤ max_i ‖ev_{z_i}‖ + L_μ(p)/w_min and ‖p‖_* ≤ ‖p − t_0‖_* + |t_0| ‖1‖_* ≤ A + B L_μ(p). So L_μ(p)/‖p‖_* ≥ g(L_μ(p)) ≥ g(r_0(δ)) with g(s) := s/(A + Bs) increasing. For constants p = t > 0, L_μ(p)/‖p‖_* = m/‖1‖_* ≥ w_min/‖1‖_* = 1/B > g(s) for all s ≥ 0. Hence r(δ) ≥ g(r_0(δ)). Both inequalities give r = 0 ⟺ r_0 = 0 and r_0/(A + B r_0) ≤ r ≤ r_0.

(b3) |E(1)| ≤ ‖E‖ ‖1‖_* ≤ ε‖1‖_* < m, so s_E > 0 lies in the stated interval, L̂(1) = s_E (m + E(1)) = m, and Φ(L̂) = Φ(L_μ + E) (scale invariance, PD-T?…-301(c)). For a cone C and s > 0, dist(sL, C) = inf_{L″ ∈ C} ‖sL − sL″‖ = s · dist(L, C). Combine with (b1).

(b4) PD-T?…-301(c): Φ restricted to the slice {L(1) = 1, M_n(L) ≻ 0} and its polynomial inverse are locally Lipschitz; Φ(L_μ + E) = Φ((L_μ + E)/m) for E ∈ H_0 (scale invariance) and Ψ(Φ(μ)) = 0, which gives η_0, c_1, c_2. If r_0(δ) ≥ c_2 η and ‖Ĥ − Φ(μ)‖ ≤ η, then E := Ψ(Ĥ) ∈ H_0 has ‖E‖ ≤ r_0(δ), so L_μ + E = m Φ^{-1}(Ĥ) ∈ C(K_δ) by (b2)(i), and (a) applies (M_n(Φ^{-1}(Ĥ)) ≻ 0 by PD-T?…-301(b)). If r_0(δ) < c_1 η, (b2)(i) gives E ∈ H_0 with ‖E‖ ≤ c_1 η and L_μ + E ∉ C(K_δ); then Ĥ := Φ(L_μ + E) has ‖Ĥ − Φ(μ)‖ ≤ η and is not an exact section pair on K_δ.

(c) Φ(μ) itself.

(d) Standard.
