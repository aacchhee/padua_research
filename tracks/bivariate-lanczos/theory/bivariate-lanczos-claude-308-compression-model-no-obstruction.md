## Statement

Square case M = N_n, Π_n-unisolvent nodes, positive weights, H = Φ(μ). For every δ > 0 there is ρ(δ) > 0 such that every pair of real symmetric N × N matrices (Ĥ_x, Ĥ_y) — consistent or not — with ‖Ĥ_x − H_x‖ + ‖Ĥ_y − H_y‖ < ρ(δ) is a compression Ĥ_x = Vᵀ X′ V, Ĥ_y = Vᵀ Y′ V (V an isometry) of a commuting pair of real diagonal matrices (X′, Y′) whose joint spectrum lies in K_δ; equivalently Ĥ_x = Σ_k x_k T_k, Ĥ_y = Σ_k y_k T_k with T_k ⪰ 0, Σ_k T_k = I, (x_k, y_k) ∈ K_δ. In contrast, the section (Krylov/graded) model can be obstructed for every δ ≤ δ_0 in reading (E), i.e. for specified consistent perturbations given as data (PD-N?…-301); the finite-precision reading (G) is not addressed. Hence the obstruction comes from the graded Krylov structure (moments up to degree 2n+1), not from non-commutativity of the computed pair as such.

## Definitions

Degree-1 matrix moment cone 𝒦(K) := {(Σ T_k, Σ x_k T_k, Σ y_k T_k) : T_k ⪰ 0, (x_k, y_k) ∈ K, finitely many k} ⊂ Sym_N³.

## Proof or evidence

Rows r_i ∈ ℝ^N of the square orthogonal Q satisfy Σ_i r_i r_iᵀ = I, H_x = Σ x_i r_i r_iᵀ, H_y = Σ y_i r_i r_iᵀ, and span ℝ^N. 𝒦(K_δ) is a closed convex cone (generated by the compact set {T ⊗ (1,z) : T ⪰ 0, tr T = 1, z ∈ K_δ}, which misses 0). Its dual cone (trace pairing) is {F = (F_0, F_x, F_y) : F(z) := F_0 + xF_x + yF_y ⪰ 0 ∀ z ∈ K_δ}. A point is interior iff it pairs strictly positively with every nonzero dual element. Pairing with P_0 = (I, H_x, H_y): ⟨F, P_0⟩ = Σ_i r_iᵀ F(z_i) r_i ≥ 0. If it is 0, each φ_i(z) := r_iᵀF(z)r_i is affine, ≥ 0 on B(z_i, δ) and 0 at its centre, hence ≡ 0 on the ball; as F(z) ⪰ 0 there, F(z) r_i = 0 for all z in the ball, and three affinely independent such z give F_0 r_i = F_x r_i = F_y r_i = 0. Since the r_i span ℝ^N, F = 0. So P_0 is interior, and (I, Ĥ_x, Ĥ_y) ∈ 𝒦(K_δ) for Ĥ close to H, i.e. Σ T_k = I, Σ z_k T_k = Ĥ. Dilation: write T_k = B_kᵀ B_k (B_k of size rank T_k × N), V := [B_1; B_2; …] (isometry since Σ B_kᵀB_k = I), X′ = ⊕_k x_k I, Y′ = ⊕_k y_k I; then VᵀX′V = Σ x_k T_k.
