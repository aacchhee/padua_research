## Statement

**Target (OPEN; precise quantified form itself to be fixed before a proof attempt).** Setting of PD-T?…-201/-202: BJ selection, block window, relations (H1) for F and their J-analogues, run in floating point with unit roundoff u, vectors stored in working precision. A *reorthogonalization rule* chooses at every step k the set L_k ⊆ {l < min W_k} and the coefficients h_k, g_k as functions of the data computed so far (any number of passes, any precision of the inner products). Original claim (verbatim above), proposed formalisation:

(U) There are node sets with positive weights — non-product, e.g. the rotated squares or the triangle of the L2 benchmarks — and constants c > 0, ρ > 1 such that, for every reorthogonalization rule and every n with U(n), the computed run satisfies max_{s<n} δ_J(s) ≥ c·ρⁿ·u·‖J‖₂ (δ_J as in PD-T?…-208), even though S_n has orthonormal bases computable to accuracy poly(n)·u (e.g. via a well-conditioned reference basis).

In words: the exponential span drift of the BJ recurrence on such measures is independent of how (or how much) one reorthogonalizes. Any rule that changes the *selection* (which product creates each column) or stores vectors in higher precision is outside (U): PD-T?…-206 shows that the selection changes the drift by 7–10 decades, and PD-T?…-115 (c) that long-double storage scales the loss with the storage precision.

## Proof or evidence

No proof. **Heuristic (not a proof).** For every relation, span Q̂_{≤k} = span(Q̂_{<k}, B_kq̂_{p(k)} − f_k), so the coefficients (h_k, g_k) of step k change the computed spans only through the rounding f_k. Degree by degree, Ŝ_t = Ŝ_{t−1} + span{B_kq̂_{p(k)} − f_k : deg k = t}. A different rule changes each parent q̂_{p(k)} (degree t−1) only by a scalar factor and by a vector v of Ŝ_{t−1} (the span of the columns preceding it), so B_kq̂_{p(k)} changes by B_kv ∈ B_kŜ_{t−1}, which lies in the old Ŝ_t up to the B_k-defect of the computed spaces, ‖(I − Π̂_t)B_kv‖ ≤ δ_{B_k}(t−1)‖v‖ (PD-T?…-208), and rounding. So, to first order, the new Ŝ_t differs from the old one only by rounding and by defects that the rule did not create. This suggests that the drift is generated by rounding and propagated by the selection essentially independently of the reorthogonalization rule — the content of (U) — but it neither bounds the amplification from below nor controls the second-order effect of the rule on the rounding terms.

## Later independent results (original target remains OPEN)

Quantifier note (IDEA-253; an IDEA disposition, not a PD-N). Read pathwise, for every rule and every error realization admitted by an upper-bound model that allows the zero error and exact-real projection, (U) is false for a trivial reason: the zero-error exact run has exact spans, δ_X=δ_Y=0, and Ĥ_J=H_J by PD-T032 part 2. This disposes only of that reading. It does not refute literal working-precision storage, a fixed IEEE implementation or a worst-case-over-errors reading. A final formalization of (U) must choose among the every-error, worst-case-error and deterministic-IEEE quantifiers rather than interchange them.

Fixed-degree instance of the heuristic in Proof or evidence (PD-N062). Take an exact prefix through degree t and fixed admissible degree-(t+1) raw products. Then the span identity of the heuristic is exact for every coefficient choice: after a source f in one raw product, every rule that only subtracts prior vectors and rescales gives the same computed span. Its angle is θ_(t+1)=||f_⊥||/sqrt((1+α)²b²+||f_⊥||²). Its defects are δ_A(t)=κ_Aθ_(t+1), with κ_(A_m)≥b for the operator A_m forming the perturbed column. This holds for any positive measure with U(t+1) and M>N_(t+1), product or not, and any admissible selection. The defect is not specific to J or to unformed products: on T_3 with BJ and the source in Yq_x, δ_Y(1)=(√3/2)δ_X(1). The conclusion is a fixed-degree O(u) obstruction, not exponential amplification; neither implicit-section in-span error nor scalar-operation realizability follows. Parent-repair and reference-basis rules, including the experiment named in Open items, lie outside that class (deferred, IDEA-256). That experiment's literal wording is ambiguous: reorthogonalizing the parent against a basis of a computed span that contains it gives zero. IDEA-256 fixes two nonzero readings, neither yet run. R17a uses the stored columns strictly before the parent's graded index and stays in the computed span. R17b projects the parent onto an extended-precision nested reference basis of the exact span of the monomials through its index; that is the only step where information outside the stored columns enters. Both leave exact parents unchanged, so neither evades the fixed-degree lemma. (U) remains OPEN.
