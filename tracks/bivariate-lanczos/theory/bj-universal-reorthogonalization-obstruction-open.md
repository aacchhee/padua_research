## Statement

**Target (OPEN; precise quantified form itself to be fixed before a proof attempt).** Setting of PD-T?…-201/-202: BJ selection, block window, relations (H1) for F and their J-analogues, run in floating point with unit roundoff u, vectors stored in working precision. A *reorthogonalization rule* chooses at every step k the set L_k ⊆ {l < min W_k} and the coefficients h_k, g_k as functions of the data computed so far (any number of passes, any precision of the inner products). Original claim (verbatim above), proposed formalisation:

(U) There are node sets with positive weights — non-product, e.g. the rotated squares or the triangle of the L2 benchmarks — and constants c > 0, ρ > 1 such that, for every reorthogonalization rule and every n with U(n), the computed run satisfies max_{s<n} δ_J(s) ≥ c·ρⁿ·u·‖J‖₂ (δ_J as in PD-T?…-208), even though S_n has orthonormal bases computable to accuracy poly(n)·u (e.g. via a well-conditioned reference basis).

In words: the exponential span drift of the BJ recurrence on such measures is independent of how (or how much) one reorthogonalizes. Any rule that changes the *selection* (which product creates each column) or stores vectors in higher precision is outside (U): PD-T?…-206 shows that the selection changes the drift by 7–10 decades, and PD-T?…-115 (c) that long-double storage scales the loss with the storage precision.

## Proof or evidence

No proof. **Heuristic (not a proof).** For every relation, span Q̂_{≤k} = span(Q̂_{<k}, B_kq̂_{p(k)} − f_k), so the coefficients (h_k, g_k) of step k change the computed spans only through the rounding f_k. Degree by degree, Ŝ_t = Ŝ_{t−1} + span{B_kq̂_{p(k)} − f_k : deg k = t}. A different rule changes each parent q̂_{p(k)} (degree t−1) only by a scalar factor and by a vector v of Ŝ_{t−1} (the span of the columns preceding it), so B_kq̂_{p(k)} changes by B_kv ∈ B_kŜ_{t−1}, which lies in the old Ŝ_t up to the B_k-defect of the computed spaces, ‖(I − Π̂_t)B_kv‖ ≤ δ_{B_k}(t−1)‖v‖ (PD-T?…-208), and rounding. So, to first order, the new Ŝ_t differs from the old one only by rounding and by defects that the rule did not create. This suggests that the drift is generated by rounding and propagated by the selection essentially independently of the reorthogonalization rule — the content of (U) — but it neither bounds the amplification from below nor controls the second-order effect of the rule on the rounding terms.
